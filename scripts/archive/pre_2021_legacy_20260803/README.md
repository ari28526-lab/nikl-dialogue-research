않는다. 내부 경로는 당시 구조를 가리킬 수 있다.

`docs/RUNBOOK_production_2020_2025.md`에 적힌 wrapper만 사용한다.

이 이동은 2020 최종 TextGrid·DB·계약 또는 현행 6-tier exporter와 연도 큐
코드를 변경하지 않았다.
