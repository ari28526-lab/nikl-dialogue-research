# reference/colab_search — 코랩 검색 시스템 원본 (읽기 전용)

> ⚠️ **실행 금지·수정 금지.** 여기 있는 코드는 1기(2026 겨울~3월) Google
> Drive(`G:/내 드라이브/DATA_2026/`)에서 돌던 **검색 시스템의 원본 스냅샷**이다.
> 새 검색 코드는 이걸 **참고만** 하여 `scripts/`에 신 D: 구조(`paths.py`)
> 기준으로 새로 짠다. 이 폴더의 코드를 그대로 돌리려 하지 말 것
> (경로·데이터가 전부 옛 G: 기준이라 동작하지 않음).

## 왜 여기 있나
- 궁극적으로 코랩 작업을 로컬/Codespace로 옮기며 **검색 코드를 재작성**할
  예정. 그 전에 옛 코드의 **기능을 함수 단위로 검토**하기 위해, 원본을
  참고용으로 리포에 확보해 둔 것.
- 이관 시점: 2026-07-15. 이후로는 검토·재작성에 **G: 드라이브를 다시 열
  필요 없음** (코드가 전부 로컬에 있음).

## 가져온 것 / 뺀 것
- **가져옴**: 노트북(`.ipynb`)·파이썬(`.py`)·문서(`.md`)·테스트 결과(`.txt`)
  = 코드·문서만 (34개 파일, ~0.55MB).
- **뺌 (의도적)**:
  - 검색결과 CSV 전부 (각 폴더 `search_results/`) — **데이터**라 불필요.
  - `60.../file_index.csv` (1.2GB) — 구식. 로컬은
    [scripts/python/fetch_audio_for_search.py](../../scripts/python/fetch_audio_for_search.py)
    가 utterance_id에서 경로를 직접 유도하므로 인덱스 파일이 필요 없음.
  - `*_OLD*`, `_deprecated/`, `__pycache__` — 원본에도 폐기 표시된 것.

## 검색 시스템 구조 (G: 원본 그대로 미러링)
| 폴더 | 역할 |
|---|---|
| `30_search_dictionary/` | **사전 기반 후보 검색** — 어휘목록에서 현상별 후보 단어 추출. `utils_phonology.py`가 공용 음운 엔진(★ 핵심). 현상별: 34 ㄴ/ㄹ삽입·35 비음화/유음화·36 합성어경음화 |
| `37_vowel_harmony_collision/` | **모음 현상** — 사전 + LS·서울·대화 코퍼스 검색 노트북 묶음 |
| `40_search_LS_corpus/` | 후보 단어를 **어휘의미(LS) 말뭉치**에서 빈도 검색 |
| `50_search_seoul_corpus/` | 후보 단어를 **서울코퍼스**에서 검색 (발음 전사 대조) |
| `60_search_dialogue_corpus/` | 후보 단어를 **일상대화 말뭉치**에서 검색 (본 자료). Stage A 검색 + Stage B 음성 수집 |

파이프라인: **사전에서 후보 추출(30/37) → 각 코퍼스에서 실제 용례 검색(40 LS / 50 서울 / 60 대화)**.
