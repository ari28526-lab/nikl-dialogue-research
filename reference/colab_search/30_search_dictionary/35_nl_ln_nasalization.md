# 유음화/비음화 환경 검색

**작성일**: 2026-02-10
**노트북**: `35_nl_ln_nasalization.ipynb`

---

## 🎯 목적

**유음화/비음화 관련 음운 환경**을 사전에서 검색

- ㄴㄹ → ㄹㄹ (유음화)
- ㄹㄴ → ㄹㄹ (유음화)
- 비음+ㄹ → 비음+ㄹ 또는 비음+ㄴ
- 저해음+ㄹ → 저해음+ㄹ 또는 비음+ㄹ

---

## 🔍 검색 조건

### 1. 형태소 경계 (dict_morph 기준)

| 환경 | 로마자 | 예시 | 현상 |
|------|--------|------|------|
| **ㄴ+ㄹ** | n + l/r | 신-라, 진-리 | 유음화 [실라], [질리] |
| **ㄹ+ㄴ** | l + n | 칼-날, 물-난로 | 유음화 [칼랄], [물란로] |
| **비음+ㄹ** | m/n/ng + l/r | 심-리, 강-력 | 유음화 |
| **저해음+ㄹ** | k/t/p/s + l/r | 독-립, 출-력 | 비음화 또는 유지 |

### 2. 단어 내부 (형태소 경계 없음)

- 같은 환경이지만 형태소 경계가 없는 경우
- 예: 관-리 (형태소 경계) vs 관리하다의 '관리' (애매)

## 📊 출력 컬럼

| 그룹 | 컬럼 | 설명 |
|------|------|------|
| 기본 | word, sense_id, definition | 단어 정보 |
| 환경 | **boundary_type** | morpheme / internal |
|  | **env_type** | ㄴㄹ / ㄹㄴ / 비음ㄹ / 저해음ㄹ |
|  | consonant1, consonant2 | 자음 (로마자) |
| 형태소 | dict_morph, word_roman | 형태소/로마자 |
|  | morph1, morph2 | 형태소 (경계만) |
|  | morph1_roman, morph2_roman | 형태소/음절 로마자 |
|  | seg_morph, anal_morph | 비교용 |
| 발음 | pron, pron_roman | 사전 발음 |
| 빈도 | freq_LS_total, freq_MP_total | NIKL 코퍼스 빈도 |
|  | freq_06b, freq_13a | 강범모·김흥규 2009 |
| 검토 | review_status, notes | 수동 검토용 |

## 🔧 주요 함수

### 1. `get_consonant_type(roman_char)`

자음 분류:
- `'nasal'`: 비음 (m, n, ng)
- `'liquid'`: 유음 (l, r)
- `'obstruent'`: 저해음 (k, t, p, s, ch, etc.)
- `'vowel'`: 모음

### 2. `check_nl_ln_at_boundary(morphemes_kor, morphemes_roman)`

형태소 경계에서 환경 확인

### 3. `check_nl_ln_internal(word_roman)`

단어 내부 연속 2음절에서 환경 확인

## 🎯 차이점: ㄴ 삽입 vs 유음화/비음화

| 항목 | ㄴ 삽입 (34) | 유음화/비음화 (35) |
|------|-------------|-------------------|
| 조건 | 자음 + i/j(y) | ㄴㄹ, ㄹㄴ, 비음+ㄹ, 저해음+ㄹ |
| 현상 | ㄴ/ㄹ 추가 | 자음 변화 |
| 경계 | 형태소 경계만 | 형태소 경계 + 단어 내부 |
| 예시 | 솜이불 [솜니불] | 신라 [실라] |
