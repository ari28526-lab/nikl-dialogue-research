## 2. 포함한 조합 검색

| ID | 조합 조건 | 확인 목적 |
|---|---|---|
| Q1 | 좌 종성 + 우 무음초성 ㅇ + i/y계 중성 | ㄴ 삽입 등 광의 후보 환경 |
| Q2 | `이/JKS·JKC` + 어절 마지막 형태소 | 형태소·POS·위치 결합 |
| Q3 | 종성 slot + 복수 구성 자모 | 겹받침 검색 |
| Q4 | 중성 slot + 복수 구성 자모 | 복합모음 검색 |
| Q5 | 형태소 첫 unit + 독립 자모 | ㄴ·ㄹ 등 독립 표면형 보존 |

| Q7 | 어절 사이 + 좌 종성 + 우 무음초성 | 어절 내부·사이 경계 구분 |

각 검색식은 60발화 전체에서 실행한다. 검토표에는 현재 12발화 bundle에
포함된 대표 결과를 검색별 최대 2건만 보인다. `60발화_적중행`은 전체
검색의 적중 행 수다.

## 3. 한 결과에서 확인할 것

1. `적중근거`가 `검색식_안내`의 조건을 실제로 만족하는가
2. WAV·TextGrid·CSV가 같은 `utt_id`를 여는가
3. TextGrid의 `[MORPH]`, `[MORPH_R]`가 검색 결과를 확인하는 데 도움이
   되는가

검토 열:

- `조건_일치`: 구조화 조건과 사람이 읽은 근거가 같은가
- `파일_연결`: 세 링크가 같은 발화인가
- `표시_이해`: 결과와 TextGrid 표시를 함께 이해할 수 있는가
- `판정`: 검색·연결 인프라를 승인할 수 있는가
- `메모`: 문제가 있을 때만 기록

## 4. 판정하지 않는 것

- Q1 결과에서 ㄴ이 실제로 삽입됐는지
- 겹받침이 실제로 두 phone으로 실현됐는지
- MFA phone이 음성학적으로 완벽한지

이들은 실제 연구 후보를 확정한 뒤 WAV·TextGrid를 보고 별도 판정한다.
