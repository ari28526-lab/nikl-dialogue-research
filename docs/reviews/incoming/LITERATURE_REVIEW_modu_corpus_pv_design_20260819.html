1. 지금 확정할 구현 판단

VH·HIA 중첩한 물리 패키지 + 복수 논리 사건 유지문헌은 형태·음운 요인이 중첩될 수 있음을 반복해서 보여 준다. 물리 음성을 중복시키기보다 사건 멤버십과 1차 할당을 분리하는 현재 설계가 추적 가능성이 높다.

구현에 바로 반영할 최소 변경. 맥락 manifest에 전사 단위 순위, 연속 동일 화자 묶음 ID·길이·목표 위치, 앞뒤 화자 교체, 겹침 주석, 시간차 원시값과 “휴지 해석 금지” 상태를 넣는다. 미리듣기용으로 이어 붙이는 짧은 무음은 원음의 휴지가 아니라 합성 구분자임을 HTML과 audio manifest에 표시한다.

2. 원유권 연구가 답해 주는 것

2.1 원유권(2022): 왜 한 화자의 말이 여러 조각으로 보이는가

2020 일상 대화 음성 말뭉치는 긴 휴지, 경계 억양, 경계 말 장음화 등을 특징으로 하는 억양구 단위로 전사되었다고 기술된다. 그러나 원유권은 대규모 자료에서 각 단위가 실제 억양 곡선에 근거한 억양구인지 재검증하지 못했으므로, 말뭉치 구축 단위를 억양구라고 가정했다고 명시했다(PDF 2–3쪽).

한 사람이 계속 말해도 여러 전사 단위와 여러 개별 음성 파일로 나뉠 수 있다. 연구자는 한 전사 단위를 한 발화로 놓지 않고, 동일 화자가 계속되는 동안의 전사 단위를 묶어 한 “말차례”로 분석했다. 다만 구분 기준은 화자 교체뿐이었다. 이것이 이번 PV의 operational_speaker_run에 직접적인 근거다.

중요한 시간 정보 제한. 2020 자료의 동일 화자 전사 단위 사이는 기계적으로 약 0.01초가 되도록 구성되어 억양구 사이의 실제 휴지가 소실되었다. 그러므로 다음 start − 이전 end는 원래 대화의 침묵 길이도, 자연스러운 끊김 길이도 아니다. 이 값으로 말차례 경계·운율 경계·유창성을 자동 판정하지 않는다.

또한 짧은 응답, 간투사, 머뭇거림, 활발한 상호작용은 발화 속도와 운율 단위 수에 영향을 줄 수 있으며, 낭독·인터뷰 결과를 일상 대화에 곧바로 일반화하기 어렵다(PDF 7–8쪽). 따라서 목표 구간 앞뒤의 화자 교대·필러·불완전 발화가 보이도록 하는 것이 필요하다.

2.2 원유권(2025): KOINA는 어디에서 쓰고, 어디에서는 쓰지 않는가

학위논문은 일상 대화 JSON의 id, form, original_form, speaker_id, start, end, note 구조와 음성 파일 대응을 설명한다(인쇄 47쪽, PDF 60쪽). KOINA는 F0 기반 억양 윤곽 자동 추적·시각화·주석 신뢰도 평가를 위한 별도 체계다(인쇄 52쪽 이후, PDF 65쪽 이후).

현재 PV에는 실행하지 않는다. KOINA는 PV-B 또는 정식 운율 분석 설계의 참고 자료다. 이번 미리듣기 스윕에서는 KOINA, F0 자동 추적, 운율 경계 자동 판정이 모두 금지 범위다. 다만 나중에 연결할 수 있도록 음성 자산 ID, 원천 단위 ID, 정확한 시간 범위와 SHA를 보존한다.

4. 음운변이 연구에서 가져올 공통 전략

연구 전략문헌 사례이번 PV 적용
문자열로 넓게 찾고 토큰 단위로 다시 확인/ㄴㄹ/ 연구는 JSON form 검색 후 토큰을 하나씩 검토했다(김지유 2026, PDF 3–4쪽). 관형사형 -ㄹ 경음화 연구도 말뭉치에서 구성을 수집한 뒤 음성을 연결했다.지금 후보 전부를 상태와 함께 남기고, 선택/미선택/부족을 감사 JSON으로 보존
형태론·동음이의·기저형을 별도 통제강·김(2024)은 동일한 -i 형태의 주격/서술격을 구별하고 동음이의어를 문맥으로 제외했다(PDF 10쪽). 강(2023)은 불규칙 용언과 활음화 어간이 전체 비율을 왜곡함을 보였다(PDF 2쪽).지금 경계·어미·중의·불규칙/축약 상태를 후보 근거에 보존. 자동 실현 판정은 하지 않음
희귀성과 자연발화 불균형을 그대로 보고/ㄴㄹ/ 연구는 목표어별 토큰·화자 수가 불균형함을 명시했다(PDF 5쪽). 모음조화 비조화형은 불규칙 제외 후 0.093%에 불과했다(강 2023, PDF 2쪽).지금 쿼터 부족을 실패 상태로 남기고 자동 전수 스캔·대체 현상 편입을 하지 않음
표본 상한과 화자 편중 억제김지유(2024 학위논문)는 목표어당 최대 30개, 화자당 3개 제한을 사용하고 희귀 표본에는 제한을 완화했다(PDF 28쪽).지금 연도 30개와 안정적 순위를 유지. 화자 중복 분포는 audit에 집계하되 새 강제 쿼터는 추가하지 않음
청취만 또는 그림만으로 판정하지 않음/ㄴㄹ/ 연구는 시·청각 결합, 명확한 예시와 비교, 시간 간격을 둔 재판정을 사용했다(PDF 5–6쪽). 강·김(2024)은 두 연구자가 듣고 불일치 8건에 스펙트로그램을 사용했다(PDF 11쪽).다음 정식 실현 ledger에서 판정자·반복판정·음향 근거 설계. PV에서는 “불명확/판정불가” 허용
문맥에 따라 지각이 바뀔 수 있음모음조화 연구의 청취실험은 목표 두 음절만 들을 때와 전체 문장을 들을 때 판단이 크게 달라졌다(강 2023, PDF 4쪽).지금 목표 단위와 ±2 문맥을 모두 제공하되 서로 구분하여 청취 가능하게 함
화자·어휘·접사/환경의 계층 유지강·김(2024)은 기저형·접사·토큰 빈도를 함께 다루고 혼합모형을 사용했다. /ㄴㄹ/ 연구는 동일 화자 안에서도 표면형이 달라질 수 있음을 보고했다(PDF 9–10쪽).지금 speaker_id, 자산 ID, 어휘/환경 근거를 잃지 않음. 다음 혼합효과 모형
자연발화와 통제발화의 차이를 명시김지유(2024 학위논문)는 단독·틀문장·사진 유도·자유발화를 비교했고, 말뭉치 표본의 녹음/환경 불균형을 별도로 다뤘다.다음 PV 결과를 실험 산출과 동등하게 해석하지 않음
ASR 오류도 음운론적으로 체계적일 수 있음윤·권·한(2026)은 Whisper 오류 중 음운론적 동기를 가진 오류가 23–41%였고, 방언과 모델 버전에 따라 양상이 달랐음을 보였다(PDF 1–5쪽).PV-B 모델명·버전·지역·오류 유형을 반드시 보존. 자동 출력은 gold가 아님
우리 프로젝트의 더 엄격한 원칙. 일부 선행연구는 음질 불량, 발화 실수, 동음이의어 등을 최종 분석에서 제외했다. 이번 저장소에서는 이를 그대로 흉내 내지 않고 zero-drop으로 바꾼다. 즉 입력 행은 삭제하지 않고 selected, excluded_with_reason, insufficient_context, audio_unavailable 같은 상태로 모두 보존한다.

8. 검토 방법과 한계

  • PDF 18개의 페이지 수·바이트·SHA-256을 로컬 파일에서 직접 측정했다.
  • 전체 PDF의 제목·초록·목차를 확인하고, 현재 설계에 직접 관련된 방법·한계·결론 페이지를 텍스트로 추출해 읽었다.
  • 레이아웃에 의존하는 핵심 근거는 원유권(2022) PDF 2–8쪽, 원유권(2025) PDF 59–67쪽 등을 이미지로 렌더링해 원문 표와 문단을 재확인했다.
  • 문헌의 표본 제외 관행은 프로젝트의 zero-drop 규칙과 충돌하므로 그대로 채택하지 않고 “상태+사유 보존”으로 번역했다.
  • 원유권(2022)의 약 0.01초 기계 간격 관찰은 2020 말뭉치에 대한 것이다. 2021–2025에도 동일하다고 가정하지 않으며, 실제 manifest와 선택 행의 원시 시간을 연도별로 감사해야 한다.
  • 문헌 검토는 PV 설계 근거를 보완하지만, 후보 쿼리의 정확도나 실제 음성의 판정 가능성을 대신하지 않는다. 그것은 사용자가 실행할 -PreflightOnly와 이후 미리듣기 결과로 확인해야 한다.

이 문서는 탐색 설계를 위한 내부 검토 자료다. 자동 실현 판정이나 정식 판정 ledger를 구성하지 않는다.
