A8. 현상별 공개 파생본 provenance — 구현 가능(스켈레톤)

REQUIREMENT R5의 재생성 계약을 빌더 스켈레톤으로 구현할 수 있다: 입력 = 승인 ledger + overlay provenance + 정보 코드북 + audit manifest(전부 SHA 결속), 출력 = 현상별 공개 파생본 + 재생성 manifest. localStorage·임시 HTML은 입력 계약에서 명시적으로 배제한다(§E Gate 4 합격 기준). 원문 음성· 전사 배포 범위는 이용조건 확인 전이므로 기본값을 "비식별 파생값 + exact-ID 재현 절차만"으로 두는 것을 권고한다(D4).
