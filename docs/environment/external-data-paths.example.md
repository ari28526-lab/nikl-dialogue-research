# 외장하드 원자료 경로 기록 예시

이 파일은 예시입니다. 실제 경로가 확인되면 같은 폴더에 `external-data-paths.md`를 만들어 기록하세요.

## 모두의 말뭉치 대화 코퍼스

```text
외장하드 드라이브:
E:\

원자료 폴더:
E:\path\to\modu_dialogue_corpus

작업용 pilot 복사 위치:
C:\Users\ari30\Dropbox\000_2026_summer_research\data\01_pilot_samples
```

## 원칙

- 원자료 폴더의 파일을 직접 수정하지 않습니다.
- 정규화 전사, 변환된 CSV/JSON, TextGrid는 프로젝트 폴더 안에 새로 만듭니다.
- 파일 수가 매우 많거나 용량이 크면 전체 복사 대신 pilot만 복사합니다.
