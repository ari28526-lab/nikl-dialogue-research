# MFA 파일럿 연구자 검토 워크북 설계 (역사 기록)

작성일: 2026-07-25  
대상: `pilot_review_v2_20260724/7_review_by_year_20260725`

## 목적

연도별 파일럿 60발화를 사람이 검토할 때 WAV, TextGrid, CSV, LAB를
반복해서 찾는 비용을 줄이고, 판정 기준과 시행착오를 행 단위로 남긴다.
이 워크북의 판정은 자동 MFA 점수를 대체하지 않으며, 대량 작업 전
연구자 품질 검토 기록으로 사용한다.

## 생성 도구 결정

원래 `Spreadsheets` 기능이 요구하는 `@oai/artifact-tool`로 생성하려
했으나, 현재 세션에서 모듈과 의존성 로더가 제공되지 않았다. 사용자에게
이 사실을 알렸고, 사용자가 2026-07-25에 `openpyxl` 우회를 명시적으로
승인했다.

- 실행 환경: `C:\Users\ari30\miniforge3\envs\mfa\python.exe`
- 설치 버전: `openpyxl 3.1.5`, `et-xmlfile 2.0.0`
- 설치 범위: 위 Python 환경의 패키지
- 원본 CSV 및 D: 원자료는 수정하지 않는다.

## 워크북 구조

### `안내`

검토 목적, 판정 기준, 파일 링크 사용법, 연구적 해석 제한을 기록한다.

- `co_speaker_ids`는 같은 대화 문서의 다른 참여자이며 직접 수신자
  표지가 아니다.
- `pron_reference`는 철자·규칙 기반 검색 보조 정보이며 사전 발음이나
  실제 음성 실현의 판정값이 아니다.

### `검토입력`

한 행이 한 발화다. 연도, 발화 ID, 화자, 공동 참여자, 정규형, 원문,
발음 참조, WAV·TextGrid·CSV·LAB 링크를 미리 채운다.

사람이 입력하는 열은 음성-문장 일치, 세 tier 정렬, 처음·끝 경계,
original/pron 표시, 화자 연결, 종합 판정, 재검토, 비고, 검토자,
검토일이다. 드롭다운과 조건부 서식은 가독성을 돕지만 판정값은 별도
문자열 열에도 저장되어 색에 의존하지 않는다.

### `진행요약`

전체 및 연도별 대상·완료·진행률·통과·수정 필요·보류 건수를
`검토입력` 참조 수식으로 계산한다.

### `원본인덱스`

`INDEX_ALL.csv`의 열과 값을 그대로 보존하여 검토 입력과 원자료를
분리한다.

### `선택값`

드롭다운 허용값을 기록하는 숨김 시트다.

## 우선 검토 사례

- `SDRW2300001955.1.1.164`: 이전 검토에서 찾기 어려웠던 발화
- `SDRW2300000891.1.1.331`: 숫자 1/일 발음 참조 및 화자 연결 확인

두 행은 `우선 확인` 열과 배경색으로 표시한다.

## 안전성과 재현성

1. 필수 원본 열과 발화 ID 중복을 검사한다.
2. 60발화 각각의 WAV, LAB, TextGrid, CSV 존재를 검사한다.
3. 출력은 `.partial.xlsx`에 먼저 쓴다.
4. 다시 열어 시트·행·드롭다운·수식·240개 링크·우선 사례를 검사한다.
5. 검증을 통과한 뒤에만 최종 경로로 원자적 교체한다.
6. 기본값은 기존 출력 덮어쓰기를 거부한다.
7. `--overwrite`를 명시하면 기존 워크북을 `_archive`로 이동한 뒤
   새 파일을 생성한다.

## 알려진 제한

- `openpyxl`은 수식을 계산하지 않는다. Excel에서 열 때 자동
  재계산하도록 설정했다.
- 상대경로 링크는 공식 워크북을 `7_review_by_year_20260725` 폴더
  안에서 열 때 작동한다.
- 링크 클릭 시 보안 경고가 나타날 수 있다. 해당 Dropbox 검토 묶음의
  파일인지 확인한 뒤 연다.
- Excel 16.0 COM을 이용한 자동 화면 렌더링은 `Workbooks.Open` 단계에서
  실패했다. 백그라운드 Excel 프로세스는 종료했으며 워크북은 수정되지
  않았다. 따라서 사용자가 공식 파일을 처음 열 때 열 너비·행 높이와
  상대경로 링크 작동을 한 번 확인한다.
