# 연구 개요 — 처음 보는 사람을 위한 설명 (2026-07-14)

## 무엇을 연구하나
한국어 일상대화에서 나타나는 **형태음운 변이**(ㄴ삽입, 비음화·유음화,
경음화, 모음 관련 현상 등)가 **빈도**(형태소·어절·의미 빈도, 화자·사용역
변수)와 어떤 관계인지 밝히는 사용 기반(usage-based) 음운론 연구.

## 자료
- **본 자료**: 국립국어원 모두의말뭉치 일상대화 2020-2025 —
  전사 JSON 17,156파일(발화 510만), 음성 PCM(발화별, 수백 GB)
- **참조 자원**: 형태분석 말뭉치(MP), 어휘의미 말뭉치(LS, 우리말샘
  의미번호), 자체 구축 어휘목록(53만 항: 우리말샘·표준국어대사전 매핑,
  로마자 발음), KoFREN 빈도 규준, 다층구조분석 말뭉치

   어원(고유어/한자어/외래어), 로마자 발음 두 체계

   합성어 경음화·모음조화, 사전·서울코퍼스·LS 빈도 연계
4. 형태소 분석 CSV (구형 분석기 — 이후 2기에서 전면 교체)

## 작업 방식의 특징
- 저사양 PC + 외장하드 → 밤샘 배치·체크포인트·재개 가능 설계가 기본
- 데이터(D:)와 코드·문서(Dropbox)의 분리, Colab(G:)은 GPU/대량 검색용 셔틀
- AI 조수(Claude)와 협업: 스크립트 작성·검증·문서화, 사람은 실행·판단
- 모든 결정·수치를 md 문서로 기록 — 어느 기계·세션에서든 이어서 작업 가능
