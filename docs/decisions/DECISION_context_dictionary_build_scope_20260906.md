# 문맥사전 자료 구축 우선 — 검토 ④ 반영 및 현재 작업 범위

2026-09-06. [사용자 검토 기록](REVIEW_context_dictionary_user_decisions_20260906.md)의 ①–③ 합의와 ④에 대한 범위 교정을 반영한다. [이전 계획](PLAN_context_dictionary_reset_20260906.md) 및 [방법 규약](../../outputs/reports/METHOD_context_dictionary_linguistic_protocol_20260906.md)과 충돌하는 완료 조건·선행 순서는 이 결정을 우선한다. 기존 검토본과 SHA 기록은 수정하지 않는다.

## 현재 목적

사용자 지시: “아무리 내가 학술적인 걸 고려한다고해도 일단 자료 구축이 목적이니 그런목적에서 확인 작업을 하면 될 것 같아.”

**이번 작업의 목적은 연구에 쓸 문맥사전 자료의 구축이다.** 언어학적 근거는 자료의 분류·일반화·출처·반례 처리를 타당하게 하는 데 사용한다. 구축 방법의 신규성 입증, 독립적인 WSD 성능 논문, 모든 연구 질문의 실험 완료는 이번 자료 구축의 완료 조건이 아니다.

① 동형어 사용 환경의 기술과 판별 재사용, ② 바른 분석을 적용 기본층으로 두고 사전/LS/다층위/세종/MP를 상호 보완적으로 활용, ③ 상위 부류로 일반화하면서 구체 관계·결합·예외를 보존한다는 방향을 유지한다.

## 구축 목적에 맞춘 확인

| 확인 범위 | 목적과 필요한 결과 |
|---|---|
| 자료 누락·중복 | 정한 입력 범위 대비 실제 반영 자료/건수와 제외·미확인 사유를 남긴다. 단순 발견과 실제 활용을 구별하고 재배포 중복을 독립 근거로 더하지 않는다 |
| 위치·번호·형태 대응 | 원문/표적/사전 그룹이 잘못 연결되지 않았는지 확인한다. 바른과 제공 주석의 차이, 미등재·분절·번호 미대응은 보존한다 |
| 내용·일반화 | 대표 용례뿐 아니라 상충/예외를 함께 조회한다. 자료를 망가뜨리는 과도한 병합·분리, 잘못된 관계·의미 부류가 있으면 수정한다 |
| 사용 가능성 | 항목→근거→원출현을 복원하고, 실제 바른 분석 표적에 후보/근거를 연결할 수 있는지 필요한 범위에서 확인한다 |
| 재현·운용 | 원자료/버전/SHA·추출/정규화/분류 기준·실행 범위·누락/오류 기록으로 다시 만들고 확장할 수 있게 한다 |

기존 구조 시험과 검토 사례를 가능한 범위에서 재사용한다. 새 검사는 새 연결 경로·자료형·발견된 오류 등 구체 필요에 맞춰 추가한다. 사람 확인은 자료의 체계적 오류와 실제 이용을 막는 문제를 찾는 데 집중한다. 이를 전수 정확도나 독립 성능 평가로 주장하지 않는다. 확인을 별도 파일럿 과제로 반복하며 구축을 지연시키지 않는다.

## 이번 완료물

1. **실제 문맥사전:** 동형어 후보/그룹과 형태·문법·의미·담화 조건, 용례/반례, 출처 및 관계/대응 상태를 연결한 검색·추출 가능한 자료.
2. **반영 범위와 확인 결과:** source별 실제 사용 범위, 누락·미확인·충돌·오류 및 사용 점검 결과. 전체 자료가 미반영이면 부분 구축 버전임을 명시한다.
3. **간결한 구축·사용 설명:** 자료별 역할, 분류·일반화 근거, 핵심 처리 규약, 재현 방법과 한계. 방법론 설명은 구축과 함께 작성한다.

모든 문헌 공백을 해소하거나 모든 지표·연구 비교를 완료해야만 자료를 만들 수 있는 순서는 두지 않는다. 번호 체계처럼 자료를 잘못 결속할 위험이 있는 공백은 해당 연결 전에 확인한다. 나머지 불확실성은 출처·상태를 남기며 관련 구축 단계에서 해결한다.

기존 바른 분석 전체에 대한 적용과 실제 잔여 WSD/API 요청 산정은 이 자료를 활용하는 다음 단계다. 전체 적용을 이번 사전 구축 완료의 필수 선행조건으로 두지 않는다. 새 API 호출, 모델 학습, 음성/TextGrid 변경을 이번 완료 조건에 추가하지 않는다.

## 다음 실무

**기존 탐색에서 찾은 자료를 입력 장부에 재연결하고, 확보·내용/번호 확인·어댑터 연결·실제 사전 반영 상태를 자료별로 정리한다.** LS/다층위/우리말샘/MP의 기존 자원을 재사용하고, 세종 ZIP·기술목록처럼 내용 확인이 남은 자원을 구체적으로 처리한다. 이 장부를 실제 구축 작업에 연결한다. ①–④의 개념 검토를 반복하지 않는다.

이번 범위 교정 기록 시점에는 새 자료 회수·파이프라인 수정·사전 구축·API 실행을 하지 않았다. 구체적인 자료별 기준은 이미 합의한 방향 안에서 문헌/가이드와 실제 내용을 대조해 정한다.
