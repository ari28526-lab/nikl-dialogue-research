작성일: 2026-07-24  
범위: MFA G2P 어절 전량 재정렬과 검색 마스터 CSV 전량 생성 직전 코드  
기준 커밋: `e1075ee`

## 1. 감사 목적

이 감사의 목적은 프로그램이 단순히 끝나는지 확인하는 것이 아니다. 대량 처리
결과가 연구에서 재사용될 수 있도록 다음을 보장하는 것이다.

1. 원자료와 기존 분석 레이어를 변경하지 않는다.
2. 중단·재개·부분 실패가 발화의 조용한 누락으로 이어지지 않는다.
3. 실행 성공과 음운론적 내용 타당성을 구분해 검증한다.
4. 어떤 코드·환경·입력·규칙으로 각 산출물을 만들었는지 재현할 수 있다.
5. 실패 발화와 결측이 연도·화자·세션에 체계적으로 몰려 연구 표본을 편향시키는지
   측정할 수 있다.

## 5. 연구적 위험 분류

### 표본 편향

정렬 실패·깨진 WAV·화자 구조 오류가 특정 연도나 세션에 집중되면 단순한 무작위
결측이 아니다. 완료 보고서에는 연도·세션·화자별 입력, 성공, 실패, 격리 건수를
기록하고 분석 단계에서 제외 사유를 조인할 수 있어야 한다.

### 측정 타당성

`spn` 감소는 G2P가 정렬용 발음 항목을 생성했다는 운영 증거다. MFA phones는
음성 구간을 찾기 위한 대략적 분절·라벨이며, 연구 현상의 실현 판정값이 아니다.
예측/사전 발음, MFA 분절, 연구자의 수동 실현 판정은 서로 다른 층으로 보존한다.

### 재현성

MFA 설치본에는 프로젝트 밖의 수동 패치가 있다. 버전 문자열만으로 동일 환경을
재현할 수 없으므로 패치 대상 파일의 fingerprint와 핵심 코드 패턴을 preflight에서
검사해야 한다. 각 실행은 Git 커밋, 설정, 입력 목록, 도구 버전, 옵션을 manifest에
기록한다.

## 6. 개선 수용 기준

### 공통

- 치명 실패는 0이 아닌 종료 코드로 전달된다.
- 완료 마커는 산출 검증 후 원자적으로 생성된다.
- 원자료는 수정되지 않는다.
- 실행별 manifest와 사람이 읽는 보고서가 함께 남는다.

### MFA

- 코퍼스가 세션 하위폴더 구조이고 세션 수가 비정상적으로 작지 않다.
- G2P·음향·사전 모델과 프로젝트 필수 MFA 패치를 확인한다.
- `TextGrid/lab` 비율, 실패 목록, 4개 tier, 시간 경계를 검사한다.
- `spn` 비율, 파일 대응, tier, 시간 경계와 후보 위치 찾기 용이성을 파일럿에서
  확인한다.
- 실패 시 temp와 원출력을 보존하고 성공한 해당 연도만 정리한다.

### CSV

- 필수 입력 헤더와 대상 세션 수가 기준선과 맞는다.
- 세션 CSV는 임시파일에 쓰고 행수·헤더·중복·어절 정합을 검증한 뒤 교체한다.
- 기존 출력은 유효성 확인 후에만 skip한다.
- overwrite 시 이전 파일과 실행 메타를 아카이브한다.
- 결측과 경고는 연도·세션별로 집계하고 임계값 초과 시 실패한다.

## 7. 이번 무인 작업의 경계

이번 작업에서는 대량 MFA와 검색 마스터 전량 CSV를 실행하지 않는다. 코드·문서·
테스트를 개선하고 합성자료 및 작은 검색 마스터 파일럿까지만 수행한다. 다만
전수 대조에서 확인된 F27을 제거하기 위해 작은 파생 인덱스 `file_meta.csv`는
구판을 D: 내부에 아카이브한 뒤 전수 재생성한다. `D:\00_RAW`는 읽기 전용으로
취급하며, 격리·마커 삭제·대량 산출 삭제 같은 상태 변경은 하지 않는다.
