# 문맥사전 첫 구축의 입력·해석 규약

2026-09-06. 사용자 검토 ①–④ 및 실행 요청에 따른 신규 파생 자료 규약이다. 기존 동결 파일럿 규약을 덮어쓰지 않는다.

## 번호와 형태 분석

- LS 2020 최종보고서 PDF 81쪽(본문 73쪽)은 우리말샘을 의미 목록의 기준으로 삼고, 세 자리 의미 번호가 표제어 등재 번호와 일치한다고 명시한다. 인성 001/002, 내딛다 001/002처럼 갈래뜻을 구별하는 예도 제시한다. 단순 동형어 그룹 번호만을 직접 부여한 주석으로 축약하지 않는다.
- 다층위 안내서는 우리말샘 어휘의미 번호임을 명시한다. 실제 JSON의 WSD 번호는 LS의 정수형과 다층위의 문자열형을 원값 보존 후 비교용 세 자리로 정규화한다.
- 따라서 기본형·품사·native 번호와 현재 우리말샘 snapshot의 세부 항목을 대조할 근거는 있다. 다만 자료 작성 시점과 사전 snapshot 시점이 다르고 별도 등재/분절 규약도 있으므로, 일치는 `snapshot_code_match_candidate`로 기록한다. 후보가 가리키는 그룹 ID와 세부 항목 ID를 함께 제공한다. 자동 gold로 승격하지 않는다.
- 000/777/888/999와 잘못된 번호는 일반 의미 항목으로 연결하지 않고 원주석·문맥·출현량을 보존한다. 대조에서 품사/접사 기능 불일치 항목은 먼저 제외한다.
- 대상 말뭉치에 적용할 기본층은 기존 바른 분석이다. LS/다층위의 MP는 제공 자료의 자체 주석이며 바른 산출물로 표시하지 않는다. 특히 LS 지침은 일부 접사를 앞말에 묶는 등 별도 분절 규약을 가진다.

## 첫 데이터 판의 기술 범위

1. 우리말샘 전체 항목·뜻풀이·용례·관계 원값과 그룹/세부 항목 색인.
2. 세종 기초/상세 연어 전체 XML, 연어 구성요소·문형·용례·의미 부류·선택 제약. 서로 같은 표제어라는 이유만으로 두 자료의 의미 번호를 하나로 합치지 않는다.
3. LS 세 장르 및 다층위 두 장르의 모든 document/sentence, MP, WSD 및 있는 경우 DP/SRL/ZA. 전체 sentence를 압축 원값으로 복원할 수 있게 보존하고 WSD 출현과 관계를 색인한다. WSD 주석 없는 형태소도 버리지 않는다.
4. 실제 제공 WSD 표적에 대해 조사·어미를 보존한 어절 형태소열과 좌/우 이웃 어절의 내용 형태소열을 문맥 패턴으로 집계한다. 서로 다른 의미 번호의 동일 패턴도 남겨 경쟁 근거를 조회한다. 이 두 종류는 선형 공기이며 의존관계나 좁은 의미의 연어로 단정하지 않는다.
5. 세종 의미 부류·선택 제약은 원표현·논항·역할을 색인한다. 우리말샘 음식 뜻풀이 키워드 단서는 별도 후보층이다. 이를 완성된 의미 부류 체계나 자동 의미 판별 규칙으로 간주하지 않는다.
6. 동일 내부 문서의 전후 세 발화와 화자, 음식/먹다 단서, 제공 SRL/ZA를 복원해 조회한다. 원형 먹다의 등장, 실제 제공 논항 연결, 비유가 배제된 음식 의미 확정은 각각 다른 상태다. 표적 자체를 그 표적의 음식 문맥 근거로 다시 세지 않는다.
7. MP 장르별 형태소 빈도와 기존 어휘목록/표준국어대사전 대응표를 별도 출처로 수용한다. 기존 재분석과 문자열 대응을 gold로 승격하지 않고 원컬럼을 보존한다.

이 판은 전체 입력을 수용하고 후보별 관찰 문맥을 만드는 구축 단위다. 상위 의미 부류의 검증된 일반화 규칙, 모든 비연속 구문을 대상으로 한 자동 판별 규칙, 바른 전수 적용이 완료됐다는 뜻은 아니다. 발견→보존→색인→관계 해석→판별 사용 중 어느 단계까지 구현됐는지 결과에 나눠 기록한다.

## 확인 기준

- 입력 SHA를 처리 전후 대조하고 SQLite 검사·반영량을 기록한다. 중단 파일은 `.building.sqlite`로 남고 완료 receipt 없이 사용하지 않는다.
- 모든 내부 문서와 발화를 파싱한다. 원문/원주석 복원 검사, 표적/형태·번호 대응 오류 및 자료 목록과 XML 대조를 수행한다.
- source별 빈도를 유지한다. LS와 다층위의 중복 가능성을 해소하기 전에는 독립 증거 수처럼 합산하지 않는다. 한 출현이 좌/우 두 패턴을 지지할 수 있으므로 패턴 지지도 합계를 고유 출현 수라고 부르지 않는다.
- 이번 검사는 자료 구축의 누락·연결 오류·오용 가능성을 확인하는 목적이다. 별도의 WSD 성능 평가를 구축의 선행조건으로 추가하지 않는다.
