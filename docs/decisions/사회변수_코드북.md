# 사회변수 메타데이터 코드북 · 표준화 결정 (living document)

목적: 사회언어학적 분석(변이 × 빈도 × 사회변수)을 위해, 메타데이터의 **변수 정의·
허용값·재코딩 규칙·결측 처리·연도 간 정합**을 한 곳에 정리한다. 표준화는 항상
**비파괴적**(원본 컬럼 보존 + 파생 컬럼 병기)으로 하고 여기에 규칙을 기록한다.
관련: [메타데이터 인덱스 METHODS 3.4b](METHODS_bareun_dialogue_reanalysis.md).

시작: 2026-07-16 (A단계 리뷰 중 사회변수 점검에서 출발).

## 표준화 원칙 (6)

1. **값 정규화 = 같은 개념은 하나의 값으로.** 표기·코딩 변이(띄어쓰기, 라벨 차이)를
   통제 값셋으로 통일. 원본 보존.
2. **연도·하위코퍼스 간 정합성.** 이 코퍼스 최대 약점 — 연도마다 binning·구성이 다름.
   비교 가능한 층위로 재조정하고, 무엇이 균질/불균질한지 명문화.
3. **결측(미상/NA) 일관 처리.** 하나의 결측 코드로 통일. 분석 시 "제외 vs 별도 범주"
   정책을 정해 기록.
4. **이론 기반 재코딩(raw ≠ 분석 변수).** occupation→사회계층, birthplace→방언권,
   education→순서형, age→분석 코호트. 원본 유지 + `_group`/`_norm` 파생.
5. **코드북 문서화(이 문서).** 변수마다 정의·허용값·재코딩·결측·출처.
6. **조인 무결성 + 다층 유지.** token→speaker→document 조인 정확, speaker-level과
   doc-level 분리하되 연결 가능(현 구조 유지).

### ⚠️ 연도 × 담화유형 구성 교락 (중요)
연도마다 수집한 담화유형이 다름 → **연도와 교락**. 통시 비교는 주의.

| 연도 | 일상대화 | 협력적대화 | 비통제대화 | 독백 |
|---|---|---|---|---|
| 2020 | 2,232 | – | – | – |
| 2021 | 3,289 | 854 | – | – |
| 2022 | 1,767 | 470 | 417 | – |
| 2023 | 1,973 | – | – | – |
| 2024 | 2,848 | – | – | 379 |
| 2025 | 2,288 | – | – | 639 |
- 일상대화만 6개년 균질. 협력적대화=2021–22, 비통제대화=2022, **독백=2024–25에만**.
- → "독백 vs 대화"는 사실상 "2024–25 vs 나머지"와 섞임. 통시 분석은 일상대화로 한정 권장.

### 화자 수준 (연도별 `_speakers.csv`)
- **`sex`**: 여성/남성. ✅ 깨끗(미상 미관측).
- **`age`**: ⚠️ **표준화 필요** — 2020만 `60대`(146), 2021~는 `60대 이상`. 60대(60–69)
  vs 60대이상(60+)이 **연도 간 비교 불가**하고, **A5 층화에서 `60대`(32만 토큰)·`60대이상`
  (502만) 별도 층으로 분열**. → **결정 대기: 2020 `60대`를 `60대 이상`으로 통합**(권장).
  bins: 10대/20대/30대/40대/50대/60대이상.
- **`education`**: ⚠️ 값 일관(초졸이하<중졸<고졸<대재<대졸<대학원이상)이나 **순서형
  인코딩 미적용**, 2020만 결측이 `NA` 문자열(타 연도와 코딩 불일치). → 순서형 부여 +
  결측 코드 통일.
- **`occupation`**: 통제어휘(12–15종/년): 학생·주부·무직/취업준비생·사무 종사자·전문가·
  서비스·판매/영업·단순노무·경영/관리직·기술자·기능원·기타. → **그대로는 계층 변수 아님**
  (학생·주부·무직 혼재). **결정 대기: 사회계층 스킴**(예 관리·전문 / 사무 / 서비스·판매 /
  노무·기능 / 비경제활동[학생·주부·무직] …). 언어학 판단 필요.
- **`birthplace`/`current_residence`**: 17개 시도(서울·경기·부산…)+NA. → **결정 대기:
  방언권 재코딩**(중부[서울·경기·인천·강원·충청?] / 동남[부산·울산·경남·대구·경북] /
  서남[광주·전남·전북] / 제주 …) + **방언엔 birthplace 우선** 여부. 언어학 판단 필요.

## 방침 결정 (2026-07-16, 사용자)
**이론적 재코딩은 하지 않는다 — ①원본 + ②정규화(일관성)만, ③분석범주는 분석 시로 미룸.**
- **직업**: NIKL 원 분류(12종+) **그대로 유지**. 계층 재코딩 X (직업은 직업대로).
- **지역**: 출생지·주거주지·현거주지 **3필드 다 유지**, **시도 17개 그대로**(방언권 묶기 X).
  단 세 필드·연도 간 **라벨은 일관**되게. → 감사 결과 3필드 vocabulary 이미 동일(경기/경기도 류 불일치 없음).
- 정규화는 오직 "같은 개념을 같은 라벨로"만.

## 적용된 정규화 (2026-07-16) — `speakers_normalized.csv`
스크립트 `scripts/python/build_speakers_normalized.py` → `04_metadata_index/speakers_normalized.csv`
(전 연도 통합 13,250행, **원본 컬럼 보존 + `*_norm` 파생**). 반영 규칙·건수:
- **age**: `60대`(2020, 146명) → `60대 이상`. `age_norm` bins: 10대/20대/30대/40대/50대/60대이상.
- **직업 오타**: `기술자 종자사(…)`(2021, 1명) → `기술자 종사자(…)`. → `occupation_norm`.
  ※ `무직`(2021)은 **(b) 그대로 보존**(2021 라벨 상이 — `무직/취업준비생`과 별개로 둠).
  ※ `군인`(2021만)·`농업/임업/어업` 등은 **실제 연도별 범주**(오류 아님) → 보존.
- **학력**: 결측 `NA`(2020, 10명)/빈칸 → `미상`(`education_norm`). 순서형 `education_ord`
  = 초졸이하1<중졸2<고졸3<대재4<대졸5<대학원이상6.
- **지역 3필드**: 결측 `NA`/빈칸(80건) → `미상`(`*_norm`). 17시도 라벨은 그대로.
- **sex**: 여성/남성(결측 미관측), `sex_norm`은 결측만 미상.
- 검증: 정규화 후 옛 라벨(`60대`·`종자사`·`NA`/빈칸) 잔존 0.
