# Bareun 서버 엔진 provenance의 사후 처리 결정

- 결정일: 2026-08-01
- 대상: 2026-07-09~10 생성한 `01_bareun_raw` 5,103,356발화
- 상태: 정확한 서버 build ID는 **복원 불가**, 나머지 실행 정보는 동결

## 확인된 사실

- 클라이언트: `bareunpy==2.0.1`, Python 3.13.14
- endpoint: `api.bareun.ai:443`
- 기능: `Tagger.tags()` 배치, 실패 시 `Tagger.tag()` 단건 폴백
- 실행일: 2026-07-09~10
- 출력: 17,156 CSV, 비어 있지 않은 입력 5,103,356발화, 빈 분석 0
- 후속 검증: 다층위 2025 직접 대조 형태소 F1 0.929

당시 스크립트·API 응답·실행 로그에는 클라우드 서버의 엔진 build ID가
기록되지 않았다. 현재 서버에 질의한 값을 과거 실행 버전으로 소급하는 것도
정당하지 않다.

## 결정

1. 알 수 없는 서버 버전을 추정하거나 현재 버전으로 대체 기록하지 않는다.
2. 논문에는 위의 확인된 클라이언트·endpoint·분석일과 함께
   “클라우드 서버 기본 엔진의 정확한 build ID는 API 산출물에 보존되지 않음”을
   한계로 명시한다.
3. MFA/CSV 전수 생산은 동결된 A1 `form/tagged`를 읽기만 하므로 Bareun을 다시
   호출하지 않는다. 따라서 이후 연도 간 동일성은 동일한 동결 A1 스냅샷과
   search-master input contract로 증명한다.
4. 정확한 서버 build ID가 출판·재현의 필수 요건이 되는 경우에만 바이칼AI에
   과거 계정 실행일 기준 정보를 문의한다. 확인 불가하고 연구자가 필요하다고
   판단하면, 별도 버전 고정 환경으로 5.1M 발화를 재분석하고 기존 A1은 archive한다.

이 결정은 provenance 누락을 “해결되었다”고 가장하지 않고, 복원 가능한 사실과
불가능한 사실의 경계를 논문 방법에 그대로 보존하기 위한 것이다.
