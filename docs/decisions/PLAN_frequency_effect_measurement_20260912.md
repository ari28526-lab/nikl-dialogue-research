# 음운현상의 빈도효과: 측정 방법을 정하기 위한 연구 계획

2026-09-12 사용자 지시 반영. 목표는 단순히 더 좋은 빈도사전을 고르는 데 있지 않다. **음운현상에서 말하는 빈도효과가 무엇의 반복 경험에 관한 가설인지 정의하고, 그 경험을 어떻게 측정할지 탐색할 출발점을 만드는 것**이다. 빈도사전 간 설명력 비교는 그 다음 단계다.

## 연구 질문의 순서

1. **대상:** 어떤 음운현상의 어떤 변이를 설명하려는가? 같은 현상 이름 아래에서도 단어 내부·단어 간, 어휘화된 형식·생산적인 환경은 다를 수 있다.
2. **기제:** 개별 단어의 기억과 인출, 조음 동작의 반복, 특정 형태 결합의 학습, 문맥 예측 가운데 무엇을 가정하는가?
3. **측정 대상:** 단어 전체, 구성 성분, 활용형, 어절, 인접한 두 단위, 특정 환경의 유형 중 무엇이 그 기제에 대응하는가?
4. **경험 모집단:** 누구의 어떤 시기·장르·지역·상황에서의 노출을 근사하는가?
5. **추정과 검증:** 어떤 코퍼스·지표·분모로 측정하고, 표본 변동과 분석 오류를 어떻게 평가할 것인가?

빈도는 발음 실현률 자체가 아니다. ‘ㄴ삽입이 가능한 100회 중 60회 실현’의 60/100은 종속변수인 실현률이고, 해당 단어나 구성 성분의 사용 빈도는 설명변수다. 이 둘의 분모를 혼용하지 않는다. 인과효과를 단일 관찰 코퍼스의 상관만으로 확정하지 않는다.

## 첫 측정 후보

| 경험 또는 가설 | 측정 후보 | 해석상 주의 |
|---|---|---|
| 특정 어휘 항목의 반복 경험 | 단어 전체 기본형의 출현 빈도 | 복합어 분절과 동형이의어 합산에 민감 |
| 특정 형태·조음 연쇄의 반복 | 활용형·원 표면 어절 빈도 | 기본형 빈도와 다르며 철자형이 발음형과 같지는 않음 |
| 구성 성분의 접근성과 결합 경험 | 선행·후행 형태소 빈도, 전체어/구성 성분 상대빈도 | 비율의 분자·분모는 서로 같은 집계 정책이어야 함 |
| 특정 형태 결합 또는 음운 환경의 경험 | 두 성분 결합 빈도, P(후행 성분│선행 성분), 환경 조건부 빈도 | 어절을 넘는 결합은 현재 단일 어절 표만으로 측정 불가 |
| 규칙의 생산성과 유추 | 조건을 만족하는 서로 다른 어휘 유형 수, 유형별 분포 | 토큰 빈도와 별도 지표; 단순 사전 등재 수가 실제 사용 유형 수는 아님 |
| 경험이 여러 상황에 퍼져 있는 정도 | 출현 문서·대화·화자 수/비율, 문서 길이를 고려한 분산도 | 현재 출현 원파일 수를 곧바로 화자 분산도라고 부르지 않음 |
| 개인의 축적된 경험 | 주관적 사용 빈도·친숙도, 단어를 아는지 | 친숙도·노출 빈도 판단·어휘 지식은 다른 문항으로 구분 |
| 현재 발화의 예측 가능성 | 앞 문맥 조건부 확률, 최근 반복 횟수 | 장기 어휘 빈도와 동시에 달라질 수 있어 별도 분석 필요 |

동형이의어를 구분한 빈도가 언제나 더 적절한 것은 아니다. 소리·조음 연쇄의 반복이 관심이면 같은 음형의 여러 의미를 합친 경험이 적합할 수 있고, 의미와 연결된 어휘 항목의 인출이 관심이면 의미별 빈도가 적합할 수 있다. 철자가 다른 동음어까지 합치는 음운형 빈도는 별도 발음형 대응 작업이 필요하다. 현재 ‘같은 표제형+같은 품사’ 합산판은 그 지표와 같지 않다.

## 자료 구성

기존 서울·모두의 말뭉치 작업은 형태소·어휘 단어·어절의 합산판/구분판과 표면 어절 보조표를 만드는 단계다. 분석 결과와 미결정을 보존하며 새 API 호출 없이 진행한다. 이 단계만으로 환경 조건부 빈도, 유형 생산성, 개인 친숙도, 발음형 빈도가 모두 확보되는 것은 아니다.

다층위(ML)·어휘의미(LS)·형태 분석(MP)은 출처 및 구어·문어·메신저별 표를 보존한다. MP와 LS에서 같은 원전사를 실제 확인했으므로 기존 빈도표를 단순 합산하지 않고 원 문서로 돌아가 집계한다. LS/ML에 들어 있는 `MP` 형태 주석과 별도 MP 말뭉치를 구분한다.

추가 통합판은 같은 원출처 계열과 문서 전체 전사 해시가 일치한 재배포 문서를 한 번 센다. 여러 층위 중 ML, LS, MP 순으로 대표 주석을 선택하고 선택 기록을 남긴다. 원출처는 같지만 문서 범위·전사가 다른 경우에는 하위 우선순위 자료를 통합판에서 보류한다. 해당 자료의 고유 부분을 버린 것으로 오해하지 않도록 출처별 빈도와 보류 문서를 모두 보존한다. 이 통합판은 중복을 피한 보수적 통합이며 최대한의 합집합을 완성했다는 뜻이 아니다. 장르별 통합판을 기본으로 해석하고 전체 통합판의 장르 비율을 한국어 사용 모집단 비율이라고 가정하지 않는다.

형태 빈도는 실제 제공된 전체 품사를 센다. 의미 주석은 실제 WSD에 나타나는 품사를 따로 조사한다. 품사별로 전체 형태소 수, native 의미 주석 수, 유일하게 연결된 수, 사전 그룹 대응 후보 수, 특수번호·연결 보류·미주석 수를 제공한다. 의미 주석 밖 품사에 의미를 만들어 넣지 않는다. 의미 주석 수와 그 번호의 사전 동형어 그룹 대응 성공 수는 다르다. native 의미 번호판과 우리말샘 스냅샷 대응 후보판을 구분하며, 후자는 독립 검증된 정답으로 표시하지 않는다.

## 비교는 두 축으로 진행

이번 원문 목록 검사에서 MP 문어와 LS 문어는 각각 7,265문서이며 7,264쌍의 전사 해시가 일치했다. 구어에서는 같은 전사 해시가 양쪽에서 165문서씩 확인되었다. 이는 통합 전에 발견한 텍스트 중복 후보 수이며 통합판의 최종 선택 수와 구별한다. 따라서 **동일 전사에서 MP와 LS의 분절·품사 정책이 빈도에 미치는 영향**도 별도 측정 오차 연구로 삼을 수 있다. 원전사가 다른 표본끼리의 빈도 차이와 주석 방식 차이를 분리하는 데 유용하다.

실제 WSD 행은 NNG·NNP·NNB·NP·NR·VV·VA·VX·VCP·VCN에 집중되었다. XR 및 다층위의 EC·IC·외국어·기호 등 소수 예외도 원값으로 남긴다. 이는 관찰된 분포이지 해당 예외 품사 전체의 의미 주석이 보장된다는 뜻이 아니다.

**측정의 성질을 확인하는 축:** 같은 항목 집합에서 빈도사전의 결측률, 저빈도·고빈도 분포, 순위 상관, 로그 빈도 차이를 품사·장르·형태 복잡성별로 본다. 문서/대화 단위 부트스트랩과 같은 크기의 부분표본을 통해 코퍼스 크기 효과와 구성 효과를 구분한다. 공통 항목만 남겨 높은 상관을 얻고 미등재 항목을 숨기지 않는다. 순위 상관이 높다는 사실은 인지적 타당성의 증명이 아니다.

**음운현상과 연결하는 축:** 연구자가 확인한 동일한 발음 표본에 측정 후보를 붙여 결과가 어떻게 달라지는지 본다. 첫 사례로 ㄴ삽입을 사용하되 단어 내부/경계 간, 형태 구조, 선후행 분절, 어종, 발화 속도, 운율 위치, 화자 변인을 함께 기록한다. 다른 현상을 시작하면 이 통제 변수와 가설을 다시 정한다.

가장 작은 시작 단위는 여러 품사·빈도대·형태 구조를 포함한 약 100개 어휘/결합 후보의 측정 표와, 그중 실제로 실현 여부를 판정할 수 있는 용례 표다. 100개는 실무용 시작 규모이며 검정력 확보를 보장하는 수치가 아니다. 자동 AP/IP나 KOINA의 결과만으로 실제 실현의 정답을 만들지 않는다. 필요한 항목만 청취·음향 확인으로 보완한다.

## 분석 모형과 판단 기준

- 빈도 없는 음운·형태·사회언어학적 기준 모형을 먼저 세운다. 이항 실현은 혼합효과 로지스틱 모형, 지속시간 등 연속량은 그 분포에 맞는 모형을 사용한다.
- 서로 강하게 상관된 여러 코퍼스 빈도를 처음부터 모두 한 모형에 넣지 않는다. 동일 결과 행·동일 통제 조건에서 측정 후보를 하나씩 비교하고, 이론적으로 독립적인 구성 성분/전체어 효과 등만 별도 결합 모형으로 검토한다.
- 빈도 효과를 p값 유무로만 판단하지 않는다. 계수 방향과 불확실성, 빈도 범위별 예측 실현 확률 차이, 새 화자/새 어휘에 대한 예측 성능, 측정 정책을 바꿨을 때 결론의 안정성을 함께 보고한다.
- 학습·검증을 화자와 어휘 기준으로 구분한다. 자기 자료 빈도는 가능하면 평가 대화/화자를 제외하고 추정하며 외부 코퍼스 빈도와 나란히 둔다. 연구사전에 사용한 자료의 정답성이나 같은 원전사의 재배포를 독립 검증 근거로 사용하지 않는다.
- 로그 변환, 0빈도 처리, 품사 범위와 분모를 먼저 고정한다. 관찰되지 않은 0, 의미 미결정, 주석 대상 밖, 키 연결 실패는 각각 다른 상태다. `log(count+1)`의 1이 코퍼스 크기에 따라 다른 뜻이 된다는 점도 감도 분석에 포함한다.
- 명시적인 소수 가설과 탐색 지표를 구분한다. 특정 코퍼스에서만 유의해지는 조합을 사후 선택하여 일반적인 빈도효과로 보고하지 않는다. 효과가 작거나 방향이 불안정한 결과도 측정법의 조건을 밝히는 연구 결과로 남긴다.

향후 친숙도 조사를 한다면 코퍼스 빈도 예측과 독립된 참여자 평가를 얻고, 의미를 구별해야 하는 항목에는 맥락을 제공한다. 빈도와 친숙도의 일치를 전제로 두지 않는다. 실험 모집과 자료 수집은 아직 시작하지 않았다.

## 우선 읽을 문헌과 쓰임

1. **Lee & Kapatsinski, Frequency Effects in Morphologisation of Korean /n/-Epenthesis.** 로컬 23쪽 저자 원고를 확인했다. 전체어 빈도와 형태 구성·환경을 연결하는 직접 관련 문헌이며 주관적 빈도 판단을 사용한 방법을 읽어야 한다. 로컬 파일명의 2015는 보존하되 최종 출판 서지는 별도 확정이 필요하다. [저자 원고](https://cpb-us-e1.wpmucdn.com/blogs.uoregon.edu/dist/a/6941/files/2014/11/LeeKapatsinskiSub-s3ss6n.pdf).
2. **Song & Dalola (2019).** Korean /n/-insertion에서 화자별 주관적 친숙도를 검토한 연구다. 개인 경험을 단일 코퍼스 빈도로 대표할 수 있는지라는 문제와 직접 연결된다. [논문](https://journals.linguisticsociety.org/proceedings/index.php/PLSA/article/view/4539).
3. **Song & Dalola (2024), Exemplar Entrenchment and Effects of Word Familiarity in Korean /n/-insertion**, 한국어학계의 해당 후속 논문. 로컬 원문 첫 부분과 관련 구절을 확인했다. 방언·연령·성별과 친숙도의 관계를 함께 검토할 근거이며 2019 결과를 별개 독립 반복 연구라고 자동 간주하지 않는다. [DOI](https://doi.org/10.18855/lisoko.2024.49.3.004).
4. **Brysbaert & New (2009).** 기존의 널리 쓰이는 빈도표를 더 적합한 경험 표본과 비교한 연구로, 문제 설정 자체에 유용하다. 영어 단어 인식 과제 결과를 한국어 음운현상에 그대로 일반화하지 않는다. [대학 연구 기록](https://biblio.ugent.be/publication/599801).
5. **Gries (2008), Dispersions and adjusted frequencies in corpora.** 같은 출현 수라도 일부 문서에 집중되는지 널리 분포하는지 구분할 근거다. 실제 분산도 구현 때에는 저자가 제공한 정정·후속 자료도 확인한다. [저자 원문](https://www.stgries.info/research/2008_STG_Dispersion_IJCL.pdf), [후속 자료](https://www.stgries.info/research/dispersion/links.html).
6. **Bell et al. (2009), Predictability effects on durations of content and function words in conversational English.** 장기 빈도, 문맥 예측 가능성, 반복을 구분할 필요성을 뒷받침한다. 지속시간 연구의 결과를 삽입·탈락 여부와 동일시하지 않는다. [저자 원문](https://web.stanford.edu/~jurafsky/bell09.pdf).
7. **An (2010), Frequency, Gradience, and Variation in Consonant Insertion.** 로컬 학위논문의 목차·초반 이론 부분·관련 구절을 확인했다. 삽입 현상의 유형/토큰 빈도와 변이 문제를 정리할 배경이다. 전 269쪽을 정독한 것으로 표시하지 않는다.

문헌 범위: 로컬 ㄴ삽입 폴더, 전체 `00_참고문헌` 및 세미나 리딩 파일명을 검색했다. Dropbox 개인·공유 세미나에서 Lee–Kapatsinski 논문/포스터와 같은 크기의 로컬 대응본을 확인했으나 해시 동등성을 확인하지 않은 파일은 중복 후보로만 취급한다. 새 이론 문헌도 검색 결과에 있었지만 이번 근거로 수용하지 않았다. 영어 측정 문헌은 저자·대학·학술지 페이지를 확인했다. 현상 전체의 체계적 문헌고찰, 책의 세부 집계 지침 정독, 다른 한국어 빈도효과 논문 전수 탐색은 남아 있다.

## 이번 단계의 완료와 다음 단계

이번에는 재사용 가능한 빈도표, 품사·의미 주석 범위, 중복 선택 기록, 측정 가설의 대응표를 마련한다. 빈도효과의 존재나 최적 측정법을 확정하는 단계가 아니다. 다음 연구 단위는 **ㄴ삽입 후보에 대해 무엇의 빈도를 측정할지 명시한 항목별 측정 표를 만들고, 소수 실제 발음 용례에서 비교를 시작하는 것**이다.
