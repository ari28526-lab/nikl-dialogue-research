# 검색 도구 개선에서 기존 주석 방법을 검토하는 범위

2026-11-07 사용자가 기존 전태희 방법 등 탐색 결과의 적용 여부도 검토하도록 요청했다. 기존 분석 종료 후 재논의 결정을 이번 적용 검토로 이어간다. 모델 학습·대량 주석 실행은 별도 평가 설계가 필요한 후속 단계다.

## 검토 근거

기존 전태희 2026 적용 검토와 입력·판단 기록 초안, 출현별 연구자 판정 작업 흐름, Besra/EMU 역할 결정, TAPA 참고용 결정을 대조했다. 전태희 방법의 대상은 텍스트의 형태 분석·절 경계 및 유형·어미 의미 기능 주석이다. 이번 문서에서는 음성 전사 자동화와 구분한다. 공개 코드 저장소는 다시 열기를 시도했으나 가져오지 못해 실제 구현·라이선스 확인은 남아 있다.

## 적용 판단

| Besra 선택 사례 검토 | 검색에서 찾은 출현을 기존 음성·TextGrid와 연결해 선택 사례 검토로 넘기는 기존 진입점을 확인한다. | 원시간/클립 시간을 보존하고 저장한 판단을 출현 장부로 다시 읽어 연결을 검증한다. 기존 시험 범위를 넘는 기능은 별도 검증한다. |
| EMU-SDMS | 계층 질의나 여러 녹음의 음향 궤적 추출이 실제 필요한지 검토한다. | 기존 역할 결정대로 현재 검색 개선의 필수 이관 단계로 넣지 않는다. |

## 구현 순서

1. 바른 전수 감사 통과 후 버전별 분석·사전·음성 연결 검색을 검증한다.
2. 기존 출현별 검토 카드와 판단 장부의 진입점을 점검하고 위 표의 입력·판단 기록 중 빠진 항목만 보완한다. 동일 기능의 별도 앱이나 장부를 중복 구축하지 않는다.
3. 적용 가능한 기능, 기존 기능으로 충족되는 부분, 미확인 사항을 실제 조회 예시와 함께 보고한다. 모델 호출이나 학습 성능을 구현 사실만으로 주장하지 않는다.
4. 검증된 일반화 코드와 합성 시험, 공개 가능한 방법 기록을 기존 승인 범위에서 커밋·푸시한다.

## 남은 판단

자동 제안의 첫 평가 과업은 형태·품사 충돌 한 범위가 우선 후보다. 실제 범위와 정답 표본은 최신 연구자 확정 장부를 확인해 결정한다. 현재 사전 후보를 연구자 정답으로 전환하거나 기존 판단을 새 분석판 전체에 전파하지 않는다.

## 새 운율구조 설계와의 연결

사용자 요청으로 2026-11-07에 저장된 통사 기반 예상 운율·필수변동 가능환경 검토와 AP/IP 구분 근거·현재 검증 상태 문서를 읽었다. 검색·판단 화면에 운율 항목을 추가할 때 다음 설계를 따른다.

- 통사·의미 유형과 예상 운율은 가설로, 성조·F0·휴지·길이·청취 품질은 관찰 근거로 기록한다. 실제 AP/IP 판단과 표적 음운 실현은 별도 축으로 둔다.
- 접점의 경계와 표적 단어의 구 내 위치·거리를 구분한다. IP는 위계상 AP 경계도 포함할 수 있지만 같은 사건을 두 번 세지 않는다.
- 같은 AP 내부, 같은 IP 안 AP 경계, IP 경계, IP 없음·AP 미결정, 판단 불가를 구별한다. 예상에는 복수 가설을 허용한다.
- 가능 환경은 기준형·형태 분석에서 찾는다. 비적용·부분 적용·불확실·자료 불량도 상태로 남겨 분모를 추적한다.
- 기존 합성어 경음화 PT와 필수적 저해음 뒤 경음화의 범위, NAN의 ㄴ/ㅁ 및 NAL/LLN을 구분한다.
- 기존 서울 AP/IP 기계 후보와 48곳 검토 묶음은 검토 자료로 연결한다. 소수 후보 검토로 전수 경계 정확도를 주장하지 않는다.
