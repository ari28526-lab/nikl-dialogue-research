  빈 tagged로 기록하고 failed.csv에 남김 (누락의 전수 추적 가능)

### 3.3 의미번호 부여 (2차 레이어: 별도 산출물)
원칙: 1차(순수 바른 출력)와 물리적으로 분리 저장. 바른 분석 자체는 불변으로 보존하고,
의미번호는 파생 레이어로 부여한다 (분석기 출력과 사전 기반 추정의 구분 유지).
- 예정 출력: `D:\05_NIKL_DIALOGUE_bareun_2020-2025\02_sense_annotated\{연도}\{파일ID}.csv`
- 부여 규칙 (우선순위):
  1. 우리말샘 기준 단의어 → 해당 의미번호 확정 (근거: lexicon v2 조인)
  2. 다의어·동음이의어 → LS 구어(SXLS) sense_id 빈도 우세 의미 부여 + 신뢰도
     (우세 비율) 병기; SXLS 미출현 시 LS 전체(ALL) 분포 사용
  3. 판단 불가 → 후보 의미번호 목록만 기록 (강제 부여하지 않음)
- 각 행에 `method` 컬럼(monosemous / ls_sxls / ls_all / unresolved)을 남겨
  부여 근거를 논문에서 정량 보고 가능하게 함
- 한계: LS의 WSD는 내용어 대상 → 조사·어미는 의미번호 비부여. LS는 2020년 자료로
  신어·2020년 이후 용법은 미반영. 문맥 기반 WSD가 아니라 빈도 기반 추정임을 명시.
