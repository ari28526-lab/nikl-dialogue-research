# Claude Cowork 인계 — 4시간 연구자 중심 선행연구 종합

## 목적

연구자가 약 4시간 동안 기존 연구에 관해 떠오르는 생각을 자유롭게 종합한다.
Claude는 생각을 대신 결정하지 않고, 연구자의 메모가 근거 장부·현상별 요인
지도·범위/표본 계약·Codex 코드 초안으로 이어지게 정리한다.

## 4시간 진행

1. **0:00–0:30 자유 회상**: 수정하거나 평가하지 말고 연구자 표현 그대로 기록.
2. **0:30–1:30 근거 지도**: 직접 주장, 반례, 적용 조건, 한계, 원문 미확인을 분리.
3. **1:30–2:30 7현상 요인 지도**: 음운입력·형태론/POS·어휘·운율·화자·담화·측정 요인과 상호작용 갱신.
4. **2:30–3:15 공백과 우선순위**: 반드시 원문을 확인할 것, 새 표본/대조, 세미나에 없던 필수 환경 결정.
5. **3:15–4:00 코드 인계**: 확정하지 말고 후보 scope card, sampling frame, query/reviewer 변경 요구로 번역.

## 필수 경계

- 자유 메모 원문과 Claude의 정규화·추론을 분리한다.
- 주장마다 출처·페이지·직접/인접/방법론/미확인·확신도·`does_not_establish`를 둔다.
- 원문을 확인하지 못한 기억은 `researcher_recall_unverified`로 둔다.
- PT는 저해음 뒤 경음화, 합성어 경음화, 사이시옷을 각각 판정하고 복수 membership을 보존한다.
- NAN은 어절 내부 저해음+/ㄴ·ㅁ/ 기준층과 어절 간 운율 탐색층을 합치지 않는다.
- 필수 환경은 형태소 경계와 좌우 POS를 층화한다.
- 연구자 승인 전 동결 query/config, 원자료, 정식 realization ledger를 바꾸지 않는다.

## 문헌 탐색 기본 순서

Claude Cowork는 처음 지정된 폴더를 완전한 문헌 집합으로 가정하지 않는다. 문헌
정리와 공백 판단은 다음 순서로 수행한다.

1. 로컬 `00_참고문헌`의 해당 현상 폴더와
   `0000_형태론세미나_리딩`의 관련 주차 폴더를 먼저 읽는다.
2. 로컬 `00_참고문헌` 전체에서 저자명, 제목, 현상명, 조건 요인, 참고문헌에
   등장하는 후속 문헌을 다시 검색한다.
3. Dropbox 연결을 사용할 수 있으면 개인 세미나 폴더, 공유 세미나 폴더, 그 밖의
   관련 Dropbox 위치를 검색해 로컬에 빠진 자료, 더 최신인 자료, 이름이 다른
   사본을 찾는다. 직접 연결을 사용할 수 없으면 필요한 검색어와 대상 폴더를
   `DROPBOX_SEARCH_REQUEST_CANDIDATE.md`에 남긴다.
4. 경로, 파일명, 크기, 수정 시각, 가능한 경우 내용 해시를 비교해 실제 추가
   문헌과 중복 사본을 구분한다. 같은 문헌의 개인본과 공유본을 서로 다른 근거로
   중복 계산하지 않는다.
5. Dropbox에서만 찾았거나 새로 발견한 문헌은 우선 `candidate_unverified`로 두고,
   원문 식별과 관련성을 확인한 뒤에만 source inventory와 claim ledger의 후보
   patch에 넣는다.
6. 최종 보고에는 읽은 자료뿐 아니라 검색한 범위, 발견한 중복, 아직 비어 있는
   이론·자료 범주를 함께 적는다.

2026-08-25 확인 시점에는 ㄴ삽입 세미나 리딩 39개와 사잇소리 세미나 리딩
44개가 로컬, Dropbox 개인 세미나 폴더, Dropbox 공유 세미나 폴더에서 각각
파일명·크기·수정 시각 기준으로 일치했다. 이 일치는 현재 두 대상 폴더의 복제가
같다는 뜻일 뿐, Dropbox 전체에서 관련 문헌을 모두 찾았다는 뜻은 아니다.
