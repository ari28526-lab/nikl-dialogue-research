# 전체 대화 JSON 적용과 재개 계약

2026-09-06 사용자는 오래 걸리는 문맥사전 적용을 PowerShell에서 실행하고 중단 후 이어갈 수 있게 요청했으며, 전체 모두의 말뭉치 JSON이 대상인지 확인했다.

적용 범위는 보유한 2020–2025년 대화 JSON 17,156개 전체다. LS·다층위·세종·우리말샘은 구축된 문맥사전의 근거 자료이며, 적용 대상 대화 자료와 구별한다. 기존 바른 형태소 정보를 먼저 사용한 뒤 사전 문맥 근거를 사용한다. 후보가 있는 발화만 미리 추출해 제외하는 방식은 사용하지 않는다. 출력의 다음 처리 상태를 통해 후속 WSD 범위를 좁힌다.

원본 전수 대조 결과는 5,157,997발화 항목 중 내용이 있는 5,103,356항목과 기존 바른 발화가 일치하고, 내용이 빈 54,641항목은 기존 분석에 없다. 빈 항목에도 원본 문서·발화 ID 및 위치 연결을 보존한다. 25항목의 앞뒤 공백 차이는 기존 입력 정규화다. 분석된 51,280,814형태소의 원행과 사전 판정·근거를 모두 보존한다.

읽기 전용 사전의 정책을 그대로 사용한다. 현재 발화와 앞선 최대 3발화를 복원하며 문서 경계를 넘지 않는다. 파일별 SQLite와 발화 25개 단위 원자적 트랜잭션으로 중단·재개한다. 강제 종료 시 미커밋 구간만 재계산한다. 완료 파일은 SHA를 확인하고 건너뛴다. 실행 중복은 PID 문자열이 아닌 OS 잠금으로 막는다.

입력·사전·설정·코드는 첫 실행 계약에 고정한다. 재개 시 바뀌었으면 결과를 섞지 않는다. 새 결과는 별도 파생 경로에 쓰며 원본 JSON·바른 CSV·WAV·TextGrid·사전 DB를 변경하지 않는다. 새 API 호출이나 Git 게시를 포함하지 않는다.

준비 검증은 기존에 확인한 파일의 기술적 동등성 검사이며 새 연구 파일럿 또는 정확도 평가가 아니다. 실제 전수 실행은 사용자가 연 PowerShell에서 시작한다. [실행 안내](../../outputs/reports/RUN_context_dictionary_application_20260906.md)와 [원본 전수 대조](../../outputs/reports/AUDIT_context_application_json_scope_20260906.json)를 따른다.
