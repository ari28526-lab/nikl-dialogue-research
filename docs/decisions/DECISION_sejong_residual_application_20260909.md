# 세종 보강의 실제 출현 적용과 미결정 유형화

2026-09-09 사용자 승인: 확보한 보강 자료를 실제 보류 출현의 그룹 판별에 활용하고, 미결정 항목을 유형별로 모은다. 집계·계획만 반복하지 않고 완료 결과를 누적한다. 바른 전수 유지 여부는 미정이며 추가 유료 호출은 하지 않는다.

1. 세종 인접 형태 문맥, 독립 원문서 지지, 현재 우리말샘 후보 뜻풀이 및 명시적 문맥 조건을 결합한 기계 규칙을 사용한다. 단순 최빈 번호·첫 뜻·역사 번호 동일성으로 판별하지 않는다.
2. 원자료·기존 판정·사람 판단은 보존한다. 첫 500파일에서 새 판별 2,300개와 기존 바른 714개를 별도 장부에 보존했고, 새 판별 전부의 표적·근거 재현 감사가 통과했다. 사람 gold가 아니다.
3. 새 판별의 exact target ID만 후속 WSD 대상에서 제외하는 패치를 만든다. 이웃 미결정 표적을 위한 원 대화 문맥은 유지한다. 현행 동결 바른 실행기는 패치를 자동 소비하지 않으므로 새 유료 실행 전에 별도 연결이 필요하다.
4. 전수 사전 후보 유형 집계와 실제 대조 범위의 문맥 보류 이유를 분리한다. 방언·옛말·이름·문법적 용법을 분류하는 것은 해당 후보를 배제하거나 WSD 완료로 삼는 행위가 아니다.
5. 승인된 로컬 적용을 독립 PowerShell에서 나머지 전수로 계속한다. 완료 source 트랜잭션과 동일 규칙의 기존 판별 장부를 재사용하며, 이후 감사 통과본만 최신 사례집으로 갱신한다.
6. 첫 범위의 1.30% 표적 감소와 실제 미호출 요청 1개 제거를 구별한다. 전수 감소량이나 완료 예정일로 외삽하지 않는다.
