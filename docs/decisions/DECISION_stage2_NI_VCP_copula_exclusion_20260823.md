# 결정: NI의 VCP 서술격 `이` 제외와 표면 `요` 보존 예외

- 결정일: 2026-08-23 KST
- 결정자: ari30
- 상태: **확정 — 같은 날 표면 `요` 예외 보완**
- 적용 대상: 다음 NI query·계약 버전과 그 파생 회계
- 비적용 대상: 동결 v1 query와 기존 G1–G4 산출물의 소급 수정

## 1. 사용자 확정

> VCP 서술격 ‘이’는 NI 본모집단에서 제외한다.

같은 날 연구자는 다음 예외를 추가로 확정했다.

> 표면형에는 `요`만 나타나지만 형태소 분석상 `이요`로 나타나는 것은 빼면
> 안 된다.

학교문법에서 서술격 조사로 다루는 `이`는 사용 중인 형태소 자료에서
`VCP`로 태깅된다. 따라서 J*/E*만 제외하는 조건으로는 이 환경이 제거되지
않는다. 그러나 분석기가 표면에 없는 `이`를 복원해 `이/VCP+요/...`처럼
분석하는 경우가 있으므로 `right_pos=VCP`만으로 일괄 제외해서도 안 된다.
표면 `요` 사례는 CLM-0002의 보조사 `/요/` 탐색 환경과 연결해 별도 회계한다.

## 2. 발견 근거

Gate 2 NI 표본 두 건을 실제 `PV_SAMPLES.csv`의 `match_evidence_json`으로
확인한 결과는 다음과 같다.

| pv_id | 표적 어절 | 왼쪽 형태소 | 오른쪽 형태소 | source query |
|---|---|---|---|---|
| `PV0015` | `편인` | `편/NNB` | `이/VCP` | `QN1_N_INSERTION_INTRA_EOJEOL_V1` |
| `PV0163` | `편이에요` | `편/NNB` | `이/VCP` | `QN1_N_INSERTION_INTRA_EOJEOL_V1` |

동결 v1 query의 오른쪽 품사 조건은 다음과 같다.

```text
right_pos regex ^(?!J|E)
```

따라서 J*/E*는 제외하지만 `VCP`는 V로 시작하므로 통과한다. 이는 VCP 환경을
NI로 이론적으로 채택한 결과가 아니라, 언어학적 범주명과 말뭉치 POS 태그의
대응을 query에 충분히 반영하지 못한 설계 결함이다.

실측 근거 경로:

- `outputs/pilots/pv_seven_phenomena_20260819/samples/PV_SAMPLES.csv`
- `config/target_queries/n_insertion_production_v1_20260818.json`
  - SHA-256: `744bd8cb45769074b7299a8b553784b7cc9a436ac70f2479f1f674a98edb3ab6`
- `config/phenomenon_contracts/n_insertion_contract_frozen_v1_20260823.json`

## 3. 적용 규칙

1. 표면형에 서술격 `이`가 실제로 나타나는 VCP 환경은 NI 본모집단에서
   제외한다.
2. 표면형에는 `요`만 나타나고 형태소 분석에서만 `이+요`가 복원되는 사례는
   VCP라는 이유로 제외하지 않는다. 본모집단에 자동 포함하지도 않고, 기존
   결정대로 `요` 별도 탐색 모집단에 보존한다.
3. 따라서 후속 판정은 POS 단독이 아니라 원 표면형·어절 표면형과 형태소 분석
   연쇄를 함께 사용해야 한다. 실제 열 이름과 조인 방식은 대표 사례 실측 뒤
   동결한다.
4. 이 결정은 VCP 행을 기존 v1 산출물에서 삭제하라는 뜻이 아니다.
5. 표면 `이`가 확인된 기존 행은 zero-drop 원칙에 따라 후속 파생 회계에서
   `out_of_scope_vcp_copula`와 같이 명시적인 범위 밖 상태로 보존한다.
   표면 `요` 예외는 별도 상태로 보존한다.
6. 동결 v1 query·계약·G1–G4 후보·joined 산출물은 읽기 전용 역사적
   산출물로 유지하고 소급 편집하거나 재동결하지 않는다.
7. 실제 제외·예외 조건은 새 query v2와 새 계약 버전에서만 구현한다.
8. `VCN` 등 다른 V계열 태그의 제외 여부는 이 결정으로 자동 확정하지 않는다.

## 4. Gate 2 표본의 지위 정정

`PV0015`와 `PV0163`으로 확인한 다음 기능 결과는 그대로 유효하다.

- `required` 선택 시 read-only TextGrid 패널 자동 열림
- `not_needed` 선택 시 패널 자동으로 열리지 않음
- 파형·표적 span·6-tier 표시
- v3 revision 저장과 JSONL 내보내기

그러나 두 사례는 표면 어절이 각각 `편인`, `편이에요`여서 서술격 `이`가 실제로
나타나는 경우다. 표면 `요` 예외에 해당하지 않으며 NI 연구 내용 표본이나 NI
형태론적 환경 검증 근거로 사용할 수 없다. 저장한 revision은
`Gate 2 기능 시험(실제 판정 아님)`이라는 메모와 함께 UI 회귀 증거로만
보존한다. 이 두 건을 Gate 3 Praat 작업 후보나 정식 NI ledger로 승격하지 않는다.
