# 모두의 말뭉치 바른 동형이의어 분석의 필요 시 수행 전환

2026-10-23 사용자 계획 변경을 반영한다.

모두의 말뭉치에 대한 바른 잔여 동형이의어 분석은 이번 일괄 작업에서 제외한다.
이후 연구에서 필요할 때 해당 문맥과 표적 범위를 정해 수행한다. 이전의 전수
잔여 의미분석 계획과 후보 우선 실행 계획은 보존하되 현재 실행 지시로 사용하지 않는다.
이는 사용자의 범위 변경이며, 예산에 맞춘 임의 축소나 분석 완료를 뜻하지 않는다.

- 이번 자동 후속 작업에서는 새 유료 호출, 추가 실행기 준비 및 전수 실행을 진행하지 않는다.
- 완료된 서울·모두 기본 분석, 로컬 보강과 공통 검색·빈도 자료는 보존한다.
  서울의 의미 포함 기본 분석 완료 상태도 유지한다.
- 기존 후보 계량·우선순위 큐·실행기 코드·소량 시험·원응답과 장부는 보존한다.
  완료 응답은 향후 범위·좌표·계약을 확인하여 재사용하고, 미확정 요청은 재전송하지 않는다.
- 미결정 의미는 그대로 표시한다. 후보·기계 선택·사람 확정을 구분하고,
  오프라인 재생 검증을 새 실호출이나 새 분석 성공으로 계산하지 않는다.
- 승인된 기존 TextGrid 백업은 계속한다. 남은 백업과 최종 복구 검증이 끝나면
  현재 자료 준비 작업을 마무리하며, 연기한 모두 동형이의어 분석을 완료 조건으로 요구하지 않는다.
- 향후 요청별 분석에서도 원자료 보존, 좌표·응답 검증, 미확정 요청 재전송 금지,
  사용권 확인 및 추가지출 사전 승인 조건을 유지한다.

자동 점검 지시와 로컬 단계 등록부에도 이 결정을 반영한다. 향후 연구 질문 전체를
현재 자동화의 무기한 완료 조건으로 추가하지 않는다.
