# 서울코퍼스 KOINA 프레임 시간 연결 v2

사용자가 승인한 서울코퍼스 KOINA 전수 분석을 이어서 수행한다. 기존 바른·연구사전 결과와 원본 주석을 보존한다.

공식 KOINA v1.1.0의 F0 추출·필터, Linux Momel 실행 파일 및 인자를 사용한다. 서울 전용 연결기에서는 실제 Praat 프레임 중심으로 입력 구간을 선택하고, 선택된 첫 프레임 시각을 Momel의 0ms에 대응시킨다. 합성 포물선 4개의 정점 시각 검사, 같은 2개 녹음의 원 Momel 호출 467개 재현과 수정 재분석, 독립 결과 검증을 통과했다.

경계 외삽점, 입력 범위 이탈점, 비정상/범위 검토 값을 CSV·JSON에 보존한다. 시각이나 F0를 범위 안으로 자르지 않는다. TextGrid 추가층에는 구간 내부 기계 후보만 넣으며, 원래 7층은 전부 보존한다. 이것은 음운·억양 현상의 연구자 검증 결과가 아니다.

기존 50번 파일럿은 동결하고 수정 파일럿을 51번, 전수 실행을 52번 결과 폴더에 둔다. 수정 파일럿과 완전히 동일한 알고리즘·원자료 계약으로 전수를 처리하며 완료 파일은 검증 후 재사용한다. 모든 원음 240개와 원래 발화 구간 128,313개를 회계 처리한다. 발화가 전사되지 않았거나 유성 F0/내부 Momel 후보가 없어도 구간을 삭제하지 않는다.
