# 바른 3.3 단계별 보존과 비교 방법

> **2026-10-23 계획 변경:** 모두의 말뭉치 바른 잔여 동형이의어 분석(S3)은 이번
> 일괄 작업에서 제외하고 연구별 필요 시 수행한다. [최신 결정](DECISION_modu_bareun_wsd_on_demand_20261023.md)을
> 우선한다. 기존 완료 자료와 준비 기록은 보존하며, 승인된 TextGrid 백업은 검증을 마쳤다.
> 아래 S3의 검증 조건은 향후 요청별 작업에 적용하고 이번 완료 조건으로 요구하지 않는다.

2026-10-17 기준 방법 기록이다. 계획이 바뀌어도 완료된 단계의 입력과 실행 방법을 확인하고 재사용할 수 있도록 단계와 수정판을 분리한다. 상세 실행 등록부·원자료 대응표·영수증은 로컬에 보존한다. 이 문서에는 실제 발화 식별자나 자료 경로를 포함하지 않는다.

S1은 2026-10-17에 저장 및 전체 기술 감사를 마쳤다. 총 141,991개 요청을 검사했고 미완료 요청은 0개다. 미분석 문자 510자는 명시적 검토 항목으로 남는다. 이 기술 감사는 원문·응답·출력의 해시, 좌표, 계수, 출력 행 대응을 확인한 것이며 의미 정확도 평가나 개별 응답의 실제 엔진 버전 확인을 뜻하지 않는다. 공급자의 3.3 버전 선언과 응답별 버전 검증은 구분한다.

S2의 첫 수정판은 원문 가장자리 공백과 기본판 분석의 공백 제거 규칙 차이에서 안전 중단됐다. 완료분·실패 영수증·실행 코드와 계약을 보존하고, 원문 내 분석 구간 대응을 명시하는 별도 수정판을 시작했다. 앞선 수정판의 완료 소스를 새 수정판의 완료 수에 합산하지 않는다. 이 기록 시점에는 S2 전수 감사 및 이후 단계 완료를 선언하지 않는다.

## 단계마다 남길 기록

입력 집합과 포함·제외 조건, 분석 옵션, 코드·사전·근거자료의 SHA-256, 부모 계약, 출력 영수증, 계수, 검토 보류, 저장 및 감사 상태를 함께 고정한다. 작업 경계와 계획 변경마다 불변 스냅샷을 추가하고 최신 포인터를 갱신한다. 미완료·실패 수정판도 보존한다.

소스별 완료는 해당 범위의 저장 완료다. 전체 단계의 감사 통과로 승격하지 않는다. 부분집합을 연구에 사용하면 선택 조건과 제외 범위를 별도로 명시한다. 같은 방법을 비교할 때도 입력 집합·부모 기본판·사전 및 근거자료 버전이 같은지 확인한다. 서로 다른 수정판의 빈도나 판별 수를 묵시적으로 합치지 않는다. 보강 내부 어댑터마다 별도 전수 중간 결과가 저장됐다고 가정하지 않는다.

## 원문과 분석 좌표의 대응

원문은 그대로 보존한다. 기본 분석에 사용한 텍스트가 원문의 가장자리 공백을 제거한 구간이면, 원문 내 시작·끝 문자 위치와 원문/분석 텍스트 각각의 SHA-256을 기록한다. 좌표는 UTF-32 코드포인트 단위이며, 공백을 제거한 텍스트와 원문 내 해당 구간의 일치를 검증한다. 내부 글자 변경이나 화자 변경은 대응 성공으로 처리하지 않는다.

후속 요청의 원문 시작 위치에 분석 구간 시작 위치와 분석 상대 좌표를 더해 요청 좌표를 구한다. 단, 실제 요청의 줄바꿈 정규화가 코드포인트 길이를 보존하는지도 확인해야 한다. 이 대응 정보를 저장했다는 사실만으로 유료 실행기가 이를 올바르게 소비한다고 가정하지 않는다. 실제 실행 전 소량 시험에서 분절·좌표·토큰 소속을 검사한다.

기존 의미 근거는 원문·화자·발화·토큰/형태소 범위·형태·품사·문맥 조건이 대응할 때만 재사용한다. 후보, 기계 선택, 사람 확정, 충돌, 보류를 별도로 남긴다. 역사 의미번호는 자동 변환하지 않는다. 의미 포함 재분석에서 분절이 바뀌면 기존 기본판을 덮어쓰지 않는다.

## 완료 보고와 일정

각 단계 완료 시 결과 규모·검증 여부·남은 보류·다음 작업과 다음 단계 및 전체 잔여 예상 시간을 보고한다. 시간 범위에는 기준 시각과 실측 근거를 붙이고, 아직 측정하지 않은 유료 실행·백업 시간은 미확정으로 표시한다. 저장 완료와 감사 통과를 구분해 보고한다.

사용자는 2026-10-24까지 약 일주일을 목표로 계속 진행하도록 승인했다. 기한은 예산·차감 확인이나 자료 보존 조건을 생략할 근거가 아니다. 초과 위험이 보이면 재사용 가능한 완료 단계와 남은 범위를 제시한다.

공개 범위는 [정기 GitHub 보존 결정](DECISION_periodic_git_publication_20261017.md)을 따른다. 이 문서는 방법과 집계 상태를 설명한다. 로컬 실행 코드 전체, 입력 스냅샷 및 상세 등록부를 배포하는 재현 패키지는 아니다.

## 2026-10-23 연구별 검토로의 전환

기본 분석과 서울·모두의 오프라인 보강, 공통 출현·문맥 자료(B1), 빈도 자료(B2)는 저장과 기술 감사를 마쳤다. 서울 240녹음·406,349형태소와 모두 17,156소스·52,086,207형태소, 합계 17,396소스·52,492,556형태소가 대상이다. B2는 14개 전역 묶음의 JSONL·CSV·Parquet 출력과 회계를 대조했다. 이 완료 상태가 개별 형태·의미 판단의 정답을 보장하지는 않는다.

다음 연구는 기존 결과를 보존한 상태에서 진행한다. 서울과 모두의 예시를 짧은 대화로 검토하고, 형태 분절·품사를 먼저 판단한 뒤 필요한 우리말샘 동형어 Group ID를 판단한다. 같은 Group ID 안의 세부 뜻 구분은 필수 완료 조건으로 두지 않는다. 기존 후보·선택 근거·충돌·좌표 보류를 구별한 그룹핑은 검토할 예시를 찾는 도구이며, 묶음 전체를 자동으로 확정하는 규칙이 아니다.

사용자 판단은 해당 출현과 적용 범위, 이전 분석, 근거와 함께 별도 추가 기록으로 남긴다. 한 예시의 판단을 다른 문맥에 일괄 적용하지 않는다. 새 판단을 연구용 조회층이나 빈도판에 반영할 때는 별도 판과 변경 회계를 만들고, 기존 완료판을 덮어쓰지 않는다. 전수 그룹핑과 사람 검토는 별도 연구 작업이며, 기존 자료 준비·백업 작업의 완료 조건을 무한히 늘리지 않는다.

국소 경계 교정, 선택적 운율 주석, 모델 미세조정은 연구에 필요한 예시부터 검토한다. 국소 교정에 억양 주석을 필수로 요구하지 않으며, 전수 재정렬·전수 운율 분석을 기본 분석 완료의 선행 조건으로 삼지 않는다.

기본 분석의 미분석 문자 510자, 서울 원문 문자 범위 미확정 2토큰, 기계 의미 연결의 정확도와 연구별 단어 단위 정의는 명시적 보류로 남는다. 모두의 유료 잔여 의미 분석은 필요 시 수행으로 유예됐으며 완료로 표시하지 않는다. 이전 성공 11문맥과 미확정 4문맥은 보존하고, 미확정 요청은 재전송하지 않는다. 오프라인 응답 재생은 신규 성공 호출로 합산하지 않는다.

## 2026-10-23 승인된 자료 준비·백업 완료

기본 3.2 백업 77개와 기본 3.3 백업 49개의 기존 완료 근거를 재사용했다. TextGrid는 기존 원본 4,286,286파일·37,956,010,783바이트를 429개 ZIP·5,232,345,451바이트로 보존했다. ZIP과 요약·복구 안내를 합한 431개 대상 모두 재다운로드 SHA-256·크기·소속 검증을 통과했고, 별도 기존 파일럿을 포함한 원격 432개 전체의 이름·고유 ID·크기 집합을 장부와 대조했다. 첫 ZIP의 10,000파일과 마지막 ZIP의 6,286파일은 원격 복구본의 CRC 검사도 통과했다.

백업 완료는 명시적으로 승인된 기본 CSV·JSON 복구 패키지와 기존 TextGrid 범위에 해당한다. 보강·공통 자료·빈도 DB 전체가 새 클라우드 백업에 포함된다는 의미는 아니다. 원자료는 보존했고, 완료 분석·전수 감사를 반복하지 않았다. 재전송 위험을 피하기 위해 업로드 의도, 원격 ID 확보, 재다운로드 검증 완료를 구분하여 기록했다. 전송 중 자원 부족과 셸 응답 지연은 이력으로 남겼으며, 활성 전송 속도를 중단·대기 시간을 포함한 완료 시간으로 표현하지 않는다.

현재 승인된 자료 준비·백업 범위의 최종 인계와 완료 등록을 마치고 기존 정기 자동화를 일시정지했다. 이후 전수 그룹핑, 짧은 대화 검토, 연구 예시의 국소 교정은 별도 작업에서 계속한다. 세부 영수증·원격 식별자·실제 검토 자료는 로컬에 보존하며 이 공개 문서에는 포함하지 않는다.
