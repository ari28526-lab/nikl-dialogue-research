# 2020–2025 대화 음원·분절 품질 Gate 결정

결정일: 2026-08-07 KST
상태: 채택, 연구자 개별 제외 승인은 별도 pending

## 왜 이 결정이 필요한가

2022 post-MFA 표본에서 다음 문제가 직접 관찰되었다.

- 한 WAV에 다른 발화 또는 다른 화자의 말이 겹쳐 들림
- 발화 시작·끝이 잘린 것으로 의심되는 사례
- 주변소음이 심하여 단일 화자 음향 연구에 바로 쓰기 어려운 사례

이 문제를 2022의 20개 표본만 고치는 방식으로 처리하면 2020–2025의 기준이
달라진다. 따라서 같은 감사 코드, 같은 근거 수준, 같은 제외 범위를 6개 연도에
적용한다. 다만 원자료의 연도별 주석 관행이 다르므로, 관측값 0을 실제 현상 0으로
해석하지 않는다.

## 핵심 결정

1. 원 WAV·JSON·CSV·MFA DB·완성 TextGrid는 삭제하거나 덮어쓰지 않는다.
2. 정렬 가능한 발화는 데이터 구축 목적을 위해 정렬·TextGrid를 보존한다.
3. 겹침·소음·경계 잘림으로 연구 주 분석에 부적합하다고 연구자가 승인한 발화는
   기본적으로 `analysis_only`로 표지한다.
4. WAV 불량, 음원 대응 불명, 원 시간정보 불가능, 최종 MFA 정렬 누락처럼 정렬
   자체가 성립하지 않는 경우에만 `alignment_and_analysis`로 분리한다.
5. 원 JSON의 `발화겹침` note 또는 실제 시간구간 중첩은
   `confirmed_source_overlap` 근거다. 이는 실제 실현 발음 판정이 아니라 원자료
   구조에 대한 판정이다.
6. 인접 시간구간이 맞닿는 `boundary_abut_review`만으로는 잘림이라고 판정하지
   않는다. WAV 시작·끝 에너지, 파형, 전사 연속성 같은 추가 근거가 있어야 한다.
7. 저에너지 프레임 기반 세션 순위는 검토 순서를 정하는 noise proxy다. SNR도,
   심한 소음의 자동 판정도 아니다. 상위 5% 세션 수는 설계상 검토 예산이며 실제
   소음 유병률이 아니다.
8. 자동 제외·자동 승인·실제 음운 실현 판정·denoise는 하지 않는다.

## 6개 연도 공통 감사 결과

구조 감사는 전체 JSON 발화를 읽었고, 음향 감사는 세션별 8개 WAV를 균등하게
선택했다. 2022는 문제 세션을 추가 전수하여 표본 수가 더 많다.

| 연도 | 전체 발화 | 원자료 겹침 근거 | 비율 | 경계 맞닿음 검토 | 음향 표본 | 표본 읽기 실패 | 전수 `<=44B` |
|---:|---:|---:|---:|---:|---:|---:|---:|
| 2020 | 870,675 | 0 | 0.000% | 869,328 | 17,848 | 0 | 0 |
| 2021 | 1,416,216 | 235,476 | 16.627% | 818,295 | 33,144 | 3 | 68 |
| 2022 | 878,157 | 128,034 | 14.580% | 292,505 | 44,207 | 0 | 0 |
| 2023 | 677,494 | 0 | 0.000% | 114,303 | 15,784 | 3 | 75 |
| 2024 | 728,281 | 13,068 | 1.794% | 395,687 | 25,816 | 0 | 0 |
| 2025 | 587,174 | 16,235 | 2.765% | 130,168 | 23,416 | 0 | 0 |

해석상 주의점은 다음과 같다.

- 2020·2023의 겹침 근거 0은 “겹친 발화가 없음”이 아니다. 해당 연도 JSON에서
  동일한 방식의 note/시간 중첩 근거를 찾지 못했다는 뜻이다.
- 2020의 경계 맞닿음 99.85%는 주석 관행을 반영한다. 자동 잘림 후보가 아니다.
- 표본 읽기 실패는 탐지 신호일 뿐 전수 개수가 아니다. `<=44B` 전수 inventory가
  실제 header-only WAV의 연도별 정본이다.

전수 대조 결과 2021의 68개와 2023의 75개는 모두 정확히 44바이트인
header-only WAV였다. 2023의 75개는 기존 승인 계약의
`audio_pairing_unresolved / alignment_and_analysis`에 전부 포함되어 있다.
2021은 53개가 같은 사전 승인 범주에 포함되고, 나머지 15개는 현재 연구용
search master와 LAB에 존재하지 않으며 보존 DB에서도 `ignored=true`, interval
0이다. 따라서 이 15개는 현재 MFA 입력 제외 후보가 아니라 디스크 inventory로만
보존한다. 2021을 다시 정렬하거나 2023 후보 승인을 반복하지 않는다.

이 과정에서 구 검사기가 `<44B`만 불량으로 보아 정확히 44B인 header-only WAV를
quarantine 단계에서 놓친 경계값 오류를 발견했다. 공통 검사는 `<=44B`로
교정했다. 또한 생산 실행기가 원 WAV를 이동하던 동작을 제거하고, 입력계약별
읽기 전용 inventory를 만든다. 그중 현재 LAB와 짝을 이루어 실제 MFA 입력이 될
수 있는 ID만 승인된 `alignment_and_analysis` 집합에 포함됐는지 검증한다. LAB가
없는 디스크 잔존물은 수량과 경로를 기록하되 MFA를 불필요하게 중단시키지 않는다.

## 2022 post-MFA 438건과 검토 표본 결합

438개 `mfa_alignment_missing`과 4개 aligned control을 합친 442개 WAV를 직접
프로파일링했다.

- WAV 읽기 성공: 442/442
- 원자료 겹침 근거: 103
- 경계 맞닿음과 활성 edge가 함께 나타난 검토 신호: 104
- 상위 noise proxy 또는 연구자 보고 소음 세션: 111

세 신호는 서로 중복되며 합계로 발화 수를 계산하면 안 된다. 438건은 이미 MFA
정렬 구간이 없으므로 승인 시 `alignment_and_analysis` 후보다. aligned control
4건은 정렬 결과를 보존하며, 연구자가 품질 문제를 승인하는 경우에만
`analysis_only` 후보가 된다.

## 연도별 적용 순서

### 2020–2022: 후향 적용

1. 완성 또는 보존된 DB·TextGrid를 변경하지 않는다.
2. 공통 구조·음향 품질표를 기존 `utt_id`에 결합한다.
3. 정렬된 발화는 승인 후 `analysis_only` 보조열로 표시한다.
4. 정렬되지 않은 발화만 기존 exact-ID 절차와 결합한다.
5. 2020·2021 전수 MFA를 다시 돌리지 않는다.

### 2023–2025: 정렬 전·후 적용

1. 정렬 전에 구조 감사, 세션 음향 표본 감사, WAV 불량 확인을 수행한다.
2. 기술적으로 정렬 가능한 발화는 겹침 후보라도 정렬 본체에 유지한다.
3. 기술적 불가능 항목만 명시 승인 계약 후 본체에서 분리한다.
4. MFA 후 exact-ID 대사와 함께 품질표를 동반 CSV/Parquet에 결합한다.
5. 연도 Gate는 자동 승인 0, 원자료 변경 0, 품질표 coverage, 제외 scope의
   일관성을 검증한다.

이 순서로 2023–2025를 처리하면 2022에서 뒤늦게 발견된 문제를 다음 연도에서
반복하지 않으면서도, 전수 정렬이라는 데이터 구축 목적을 잃지 않는다.
