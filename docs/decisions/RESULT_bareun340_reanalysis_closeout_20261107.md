## 사전과 검색

2026-11-03 우리말샘 XML 25개의 고유 뜻풀이 항목 1,245,255건을 별도 SQLite 색인으로 만들었다. 완전히 동일한 중복 354건을 합쳤고 원본 해시·DB 무결성·후보 조회를 검증했다. 검색의 의미 단위는 동형이의어 Group ID다.

서울·모두 전 소스를 명시적 분석판 카탈로그에 등록했다. 두 코퍼스의 문맥 조회와 사전 후보 연결을 소량 확인했다. 기본형 검색은 선택한 분석판의 소스를 읽으며 지정한 출력 상한에서 멈춘다. 출력 개수를 전수 빈도로 사용하지 않는다.

기존 선택 검토 표본 300건을 새 판에 다시 연결했다. 원문 위치와 형태가 대응한 279건에는 새 사전 후보를 붙였고 21건은 형태 재검토 대상으로 남겼다. 이 수는 전수 검토 대상이나 잔여 오류 규모가 아니다.

## 검토 도구

- 분석판·사전판·지침판을 포함한 주석 입력을 내보낸다.
- 모델 원출력과 파싱 결과를 제안 기록으로 저장한다. 연구자 판단은 기존 검토 절차로 따로 기록한다.
- 휴대용 HTML과 답변 JSON으로 다른 PC에서 이어갈 수 있다. 중복 이벤트와 수정 충돌을 검사한다.
- 새 분석판의 출현 ID와 부모 출현 참조를 기록하며 이전 판단을 새 판에 자동 승계하지 않는다.

합성 분석판 시험 8개, 검토 서버 시험 18개, HTTP 시험 묶음 43개, 휴대용 Python 시험 15개 및 JavaScript의 답변 교환·정적 HTML 검사가 통과했다. 시험 묶음에는 중복되는 사례가 있으므로 합산한 독립 시험 수로 표현하지 않는다. 실제 브라우저의 화면·조작 검증은 이번 완료 범위에 포함되지 않았다.
