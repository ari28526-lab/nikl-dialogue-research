# B안 실행 계약과 현재 정지점

2026-09-09 사용자 확정 B안을 구현했다. 실행 안내는 `outputs/reports/RUN_wsd_plan_b_20260909.md`다.

1. 동결 입력 17,156파일·6,854,275표적을 재처리하지 않는다. SHA 확인 후 새 계획과 실행 DB만 생성한다.
2. 220자까지 인접 표적 발화를 묶고 문서 내부 앞뒤 1발화를 유지한다. 긴 단일 발화는 자르지 않는다. 원발화 사이에 다른 발화가 있으면 함께 보존한다. 문맥 연결은 의미 효과가 검증됐다는 뜻이 아니다.
3. 바른 with_sense=true, auto_spacing=true, auto_jointing=false, auto_split_sentence=false, UTF32, 단일 worker. 공식 REST 인터페이스를 표준 라이브러리로 사용해 과거 가상환경 클라이언트에 의존하지 않는다. HTTP 전송 자체의 실제 검증은 첫 본 처리에 남는다.
4. 원응답의 우리말샘 항목 ID를 해당 원출현 후보 사전의 그룹번호로 연결한다. 문맥·좌표·형태소·후보 바인딩이 맞는 실제 응답만 사용한다. 같은 그룹의 세부 뜻 차이는 완료를 막지 않는다.
5. 검증 가능한 기존 원응답 26개에서 267표적을 재사용한다. 이전 가공 WSD CSV와 첫 뜻/최빈 뜻 추정은 재사용 판정으로 승격하지 않는다.
6. 최종 482,300요청·31,939,959어절. 계획에는 전 표적이 재사용 또는 새 요청에 한 번씩 연결된다. 새 판정·오류·보류는 기존 자료 위에 덮지 않는 별도 층이다.
7. 의도→원응답 SHA→표적 판정의 독립 트랜잭션과 OS 잠금으로 중복 실행·호출을 방지한다. 원응답 불명확 시 자동 재전송하지 않는다. 본 처리 첫 50요청은 같은 장부에서 계속 사용한다.
8. Luna는 실제 바른 그룹 보류/충돌 중 형태소를 식별할 수 있는 출현만 대상이다. API 사용료 US$10을 초과하지 않도록 응답 전 최대 비용을 예약하고 오류의 예약을 유지한다. 자동 충전·추가 구매·자동 다른 모델 대체는 없다.
9. 사용자 화면은 구독 잔여 2,487,020 + 단기권 400,000이다. 추가권 사용 가능성은 검토 의사이며 구매 승인으로 취급하지 않는다. WSD 차감 배율·반올림과 최종 외부 제출 범위를 확인하기 전 실행 잠금을 해제하지 않는다.
10. 장시간 실행은 별도 PowerShell에서 한다. Codex 종료와 독립적이며 새 잔액 확인 후 재개할 수 있다. 예전 기간 추정은 현재 ETA로 사용하지 않는다.
