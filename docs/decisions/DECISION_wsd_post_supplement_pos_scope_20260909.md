# 보강 후 잔여 WSD의 품사 범위와 후보 우선순위

2026-09-09 사용자 명시: 사용빈도 자료까지 활용한 보강을 끝낸 뒤 남은 출현 중 바른으로 보낼 것은 일반명사·일반동사이며, 이어서 서술 기능의 형용사도 추가했다. 질문은 이 제한으로 실제 전송량이 줄어드는지다.

- 최종 검토 범위는 NNG + VV + VA다. NNP/NNB/NP/VX/MM/부사/감탄사/접사는 이 바른 표적 범위에 포함하지 않는다. 필요한 주변 대화에서 이 품사들을 지우지는 않는다.
- VA의 관형절 활용도 서술 기능에 포함한다. 품사 표지만으로 별도의 구문 기능 분류를 완료했다고 주장하지 않는다.
- 방언은 후보로 유지하고 일반 뜻끼리의 경쟁보다 후순위로 둔다. 우선순위를 뒤로 옮기는 것 자체로 총 호출량이 줄어들지는 않는다.
- 옛말·이름·지명은 별도 보류하고 기록을 유지한다. 후보를 보류하여 하나만 남았다는 이유로 실제 출현을 WSD 완료로 판정하지 않는다.
- 전수 보강은 계속한다. 외부 호출 범위 제한 때문에 무료 로컬 보강의 기존 완료 결과를 버리거나 다시 시작하지 않는다.
- 수량 비교는 전체 품사 / NNG+VV / NNG+VV+VA를 같은 감사 통과 보강본에서 계산한다. 이미 시도한 요청은 재전송 대상으로 잡지 않는다. 기존 요청의 문맥을 유지한 요청 수·전송 어절과 판별 표적 수를 따로 보고한다.
- 현재 500파일 적용본 r01 기준 값은 잠정치다. 전수 보강·감사 후 r02에서 자동 재집계한다. 보강 완료 전 숫자를 최종 수량이나 완료 예정일로 단정하지 않는다.
- 이번 수량 비교는 품사 제한만의 효과를 측정한다. 옛말·이름·지명 후보가 있다는 이유로 출현을 통째로 삭제하지 않는다. 이들의 실제 보류 판정에 따른 추가 변화는 이번 POS 집계의 확정 감소로 계산하지 않는다.
- 바른 새 유료 호출·자동 충전·구매는 하지 않는다. 이 결정은 실제 전송 실행 승인이 아니다.

설정: config/wsd_pos_scope_20260909.json. 집계기: scripts/python/measure_wsd_pos_scope.py. 감사 완료 후속 단계에 집계를 연결했고, 결과는 별도 F 드라이브 루트의 POS_SCOPE_latest.json 및 POS_SCOPE.html로 갱신한다.
