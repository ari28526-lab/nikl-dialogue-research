# 한국어 사용빈도 어절 표기 변이 조회

2026-09-09 사용자 요청: 전수 로컬 보강은 유지하고, 같은 어절·형태 분석이 구두점·특수기호·숫자로 과도하게 갈리는 문제부터 해결한다.

## 확인한 원인과 처리 범위

확인 파일은 사용빈도 자료의 05.txt(형태소 어절 분석 빈도), 12.txt(단어 어절 분석 빈도)다. 두 파일은 원래 표면형별 빈도표다. 쉼표 유무를 별도 항목으로 센 원파일 자체를 오집계라고 단정하지 않는다. 현재 보강 조회의 정확한 표면형 조건 때문에 관련 표기 변이 빈도를 함께 얻지 못하는 것이 이번 작업의 대상이다.

원파일·SUPPLEMENT.sqlite·완료 사전·실행 중인 전수 보강 규칙은 보존한다. 새 book_eojeol_normalized_20260909 아래 INDEX.sqlite에서 원본 variant_id/eojeol_id에 연결되는 별도 조회 키만 만든다. 동형어 판별 완료나 신규 의미 규칙으로 자동 승격하지 않는다.

- 어절 바깥의 쉼표와 허용 목록의 장식 기호만 제거한 조회 키를 추가한다. 제거 내역과 원문은 조회 결과에 남는다.
- 평서점·물음표·느낌표·혼합 기호·말줄임을 구분하고 종결어미 자체를 보존한다. 이는 종결 기호 유형이며 실제 문장 기능을 자동 판정한다는 뜻이 아니다.
- 인용·괄호 여부는 별도 조건으로 유지하고 같은 종류의 글꼴 표기 차이만 묶는다. 조사, 어미, 어절 내부의 빗금·하이픈·수학 기호 등은 제거하지 않는다.
- 숫자의 실제 값은 기본 조회 키에서 구분한다. SN 숫자만 다른 구조는 별도 numeric_template 조회에 한정한다. 단위·소수 구조·내부 기호는 남고 숫자가 포함된 일반명사를 자동 변환하지 않는다. 숫자 구조 조회의 합계는 동일 어절의 실제 빈도로 취급하지 않는다.
- 05와 12는 같은 자료를 다른 분석 수준에서 집계한 자료이므로 합산하지 않는다. 역사 의미 번호·무번호·특수 번호는 보존하며 우리말샘 번호와 자동 동일시하지 않는다.
- 원문과 분석의 구두점 위치가 맞지 않거나 분석을 읽지 못하면 보류한다. 빈도 행을 버리지 않는다.

## 다음 후보 저장에 적용할 사용자 방향

바른을 사용하지 않는 최후안: 전수 보강 후 잔여 NNG·VV·VA에 대해 LS·다층위·한국어 사용빈도 자료의 같은 어절 내부 형태 구조 빈도를 근거로 후보를 최대 5개 저장한다. 확정 WSD와 분리하고 원래 전체 후보 집합을 보존한다. 출처 중복을 무시한 빈도 합산, 사전 첫 뜻·최빈 뜻의 자동 완료, 역사 번호의 무검증 변환은 하지 않는다. 이번 색인은 그중 책의 표기 변이 조회를 보완하며 최후안 전수 후보 저장의 완료를 뜻하지 않는다.

문맥 길이 비교도 NNG·VV·VA에 한정해 유지한다. 추가 바른/Luna 호출이나 구매는 없다.
