# 연구 시작 시점의 자료·WSD 상태

2026-09-09 기준. 전수 WSD나 전수 운율 주석을 연구 시작의 선행 조건으로 두지 않는다.
현상별 후보를 검색하고 연구 표본을 정한 다음, 의미 구분이 분석에 영향을 주는 출현에
WSD를, 운율 변인이 필요한 표본에 청취·주석을 추가한다. 자동 정렬 경계는 청취 검토가
필요한 측정 기반이며, 운율 주석이나 실제 음운 실현의 정답이 아니다.

표의 수치는 서로 다른 단위와 처리 단계다. 합산하여 전체 해결률을 계산하지 않는다.
WAV에는 정본과 별도 복구 namespace가 포함되므로 발화 수와 같지 않다.

최종 후보 저장은 20:40 KST에 완료됐으며 독립 대응 검사, 중단·재개·중복 실행 차단,
전수 저장 감사와 완료 DB SHA 확인을 통과했다. 후보 저장 오류는 0건이다.
4,466,844 출현(89.03%)에 LS·다층위 또는 사용빈도 근거가 연결됐다.
나머지 550,656 출현은 근거 미연결 또는 위치 대응 보류다.
89.03%는 근거 연결률이며 WSD 정확도나 해결률이 아니다.

## 해석 계약

- 우리말샘 동형이의어 그룹까지만 구별하며 같은 그룹 안의 세부 뜻은 더 판정하지 않는다.
- 후보 순위·최빈형·첫 사전 뜻은 완료 WSD로 승격하지 않는다. 후보 저장의
  `selected_group`은 비어 있고 `wsd_completed=false`다.
- 한국어 사용빈도의 과거 번호를 현대 우리말샘 번호와 직접 동일시하지 않는다.
  책의 05·12 표는 출처별로 유지하며 중복될 수 있는 빈도 합계를 더하지 않는다.
- 쉼표·장식 기호 차이는 검색용 어절 묶음에 반영한다. 문장 유형·인용 구분은 유지하고
  숫자 틀은 별도의 약한 근거로 표시한다. 원 표기와 분석은 보존한다.
- LS·다층위의 현대 그룹 연결도 잠정 기계 근거다. 상위 5개에서 제외된 원후보와
  순위 경계의 동률을 보존한다.
- 이후 선택적 WSD의 우선 품사는 NNG·VV·VA다. 방언은 후보로 유지하되 후순위,
  옛말·이름·지명은 보류한다. 이 세부 우선순위 필터가 최종 후보 DB 전체에 이미
  적용된 것은 아니다.

## 바른 실험에서 확인한 한계

첫 50 요청은 2,673 어절·626 표적을 전송하여 447 판별과 179 보류를 남겼다.
호출 작업 시간은 약 582초였고 결과를 재사용했다. 추가 List 묶음 1회는 HTTP 503으로
처리 여부가 불명확하므로 자동 재전송하지 않는다. 별도 짧은 문맥 4회는 215 어절을
약 35초에 처리했다. 동일 표적의 긴 문맥/짧은 문맥 정확도 대조 시험은 아니다.

대량 전송 계획에서는 표적을 줄여도 주변 문맥과 요청 경계가 남아 호출 수·시간이
비례해서 줄지 않았다. 전체 바른 WSD를 빠르게 끝낼 방법은 아직 입증하지 못했다.
과거 처리율을 현재 전수 완료 예정일로 제시하지 않는다. 추가 유료 호출은 연구상
필요한 표적·최종 요청량·현재 차감 규칙과 잔액을 확인한 뒤 정한다. Luna 호출은 없었다.

## 연구에서 이어 쓰는 순서

1. 연구 질문·현상과 분석 단위를 정하고 기존 형태 검색층에서 표본을 추출한다.
2. 원 파일·대화·발화 ID와 형태소 위치로 WAV·TextGrid·후보 근거를 연결한다.
3. 의미가 표본 포함 여부나 분석 결과를 바꾸는 경우에만 그룹 판단을 보완한다.
4. 운율 변인은 연구 설계에 필요한 표본에서 청취하고 별도 주석층에 기록한다.
5. 확정·기계 선택·후보·보류를 구분해 분석하고, 불확실한 표본 포함 여부에 따른
   민감도 분석을 함께 보고한다. 판단은 출현 ID에 연결하며 원자료를 덮어쓰지 않는다.

## 공개 범위

이 문서는 집계와 처리 계약만 공개한다. 원 음성·전사·TextGrid·대형 DB·사전 및
사용빈도 원문은 포함하지 않는다. 장치 경로가 결합된 로컬 실행기는 이번 공개에서
제외했고, 완료 당시 코드와 manifest는 로컬에 보존한다.

같이 게시한 `wsd_candidate_response.py`는 제공된 후보·문맥·표적 범위를 벗어난
응답을 거절하는 독립 검증기다. 외부 호출을 하지 않으며 통과를 의미 정확도로
해석하지 않는다. TextGrid 감사기의 희소 집계에서 0인 범주가 빠지던 오류도
고정 집계 항목을 명시하는 방식으로 수정하고 회귀시험을 포함했다.
