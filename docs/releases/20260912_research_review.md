# 본격 연구 전 정리와 점검

2026년 9월 12일 19:41 KST 확인 기록. 이 문서는 특정 시점의 연구 준비 상태이며 실시간 진행판이 아니다.

**지금은 현상별 연구 표본을 구성할 수 있는 단계다. 빈도사전 전수 출력은 진행 중이며, 자동 형태·의미·음성 분석의 언어학적 정확도는 연구 표본에서 확인해야 한다.** 모든 WSD와 운율 주석의 완성을 연구 시작의 선행 조건으로 두지는 않는다.

## 1. 무엇을 위해 자료를 만들고 있는가

음운현상의 빈도효과를 연구할 때 특정 빈도사전의 숫자를 당연한 척도로 받아들이지 않고, **무엇의 반복 경험을 누구의 어떤 경험 모집단에서 어떻게 측정할지** 탐색한다. 어느 빈도사전이 음운현상을 더 잘 설명하는지는 이 측정 설계에 뒤따르는 질문이다.

현재 빈도사전은 형태소·어휘 단어·어절, 동형이의어 합산·구분, 코퍼스·장르·주석 정책의 영향을 비교할 기반이다. 발음의 실제 실현률, 개인의 친숙도, 환경별 생산성까지 이미 측정한 것은 아니다.

| 어절 | 전사 공백 단위 표면형과 형태 분석열 | 분석기 토큰과 전사 공백이 달라도 전사 어절을 누락하지 않음. 연결 실패는 보류 |

같은 표제형·같은 품사 안에서 동형이의어를 합산한 판과 구분한 판을 함께 만든다. 미결정은 후보에 임의 배분하지 않는다. 단어가 여러 형태소로 구성되면 구성 성분 하나의 의미를 단어 전체의 의미로 옮기지 않는다. 형태소의 그룹 배열이 있다고 해서 어절 전체의 의미 판별이 완료된 것은 아니다.

## 5. 다층위·LS·MP 통합의 핵심 발견

MP 문어와 LS 문어는 각각 7,265문서이며 7,264쌍의 문서 전체 전사가 같았다. 구어에서도 양쪽에 같은 전사 해시를 가진 문서 165개씩이 확인됐다. 따라서 기존 빈도표를 더하면 같은 사용례가 중복될 수 있다.

출처별 빈도표를 보존하고, 원출처 계열과 전사 전체가 같은 재배포 문서는 통합판에서 한 번 센다. 다층위→LS→MP 순으로 대표 주석을 고른다. 같은 원출처의 일부 범위만 겹치는 경우에는 정확한 경계 확인 전까지 하위 우선순위 문서를 통합에서 보류한다. 보류 문서는 출처별 표와 선택 원장에 남는다. 통합판은 보수적 통합이며 모든 고유 구간의 최대 합집합은 아니다.

같은 전사의 소표본에서 LS 구어는 604형태소, MP 구어는 608형태소였다. 문어에서도 LS 276, MP 281로 달랐다. **같은 언어 사용을 분석하더라도 주석 정책에 따라 빈도가 달라질 수 있다.** 이 차이는 어떤 분석이 더 정확한지의 결론이 아니라, 측정 단위와 분석 정책을 연구해야 할 근거다.

형태 빈도는 제공된 전체 품사를 센다. 실제 WSD는 NNG·NNP·NNB·NP·NR·VV·VA·VX·VCP·VCN에 집중되어 있다. XR과 다른 소수 태그 예외도 보존하지만 해당 품사 전체가 의미 주석되었다고 가정하지 않는다. MP에 새 WSD를 수행하지 않는다. 원 의미 번호판과 사전 스냅샷의 그룹 대응 후보판을 구별한다.

## 7. 빈도효과를 측정하기 위한 시작 설계

| 가정하는 경험 | 측정 후보 | 주의할 점 |
|---|---|---|
| 특정 어휘 항목의 반복 | 전체어 기본형 빈도 | 의미 합산·구분이 가설에 맞아야 함 |
| 특정 형태와 조음 연쇄의 반복 | 활용형·어절·두 성분 결합 빈도 | 철자 빈도와 실제 발음형 빈도 구별 |
| 성분 접근성과 결합 학습 | 구성 형태소 빈도, 전체어/성분 상대빈도, 환경별 유형 수 | 유형 빈도와 토큰 빈도를 별개로 측정 |
| 다양한 상황에서의 반복 | 출현 화자·대화·문서 비율과 분산도 | 일부 대화의 반복이 전체 빈도를 지배할 수 있음 |
| 개인의 경험 | 주관적 사용 빈도·친숙도·단어 지식 | 서로 다른 문항이며 코퍼스 빈도와 같은 개념으로 취급하지 않음 |
| 현재 문맥의 예측 | 문맥 조건부 확률과 최근 반복 | 장기 빈도와 구별하여 분석 |

먼저 하나의 현상에서 여러 빈도대·형태 구조의 어휘/결합 후보 약 100개를 시작 목록으로 삼을 수 있다. 이는 작업을 구체화하기 위한 제안 규모이며 검정력을 보장하지 않는다. 실제 사용할 후보와 표본 수는 연구자가 결정한다.

동일 항목에서 코퍼스·집계 단위·의미 정책을 바꾸어 결측, 순위, 로그 빈도 차이와 불확실성을 확인한다. 다음으로 같은 발음 표본에 측정 후보를 붙인다. 이항 실현이면 혼합효과 로지스틱 모형 등을 사용하고, 빈도 없는 기준 모형과 비교한다. 음운 환경·형태 구조·화자·발화 속도·운율 등 필요한 요인을 함께 고려한다.

빈도의 효과는 p값 유무뿐 아니라 방향과 크기, 예측 실현 확률의 차이, 새로운 화자/어휘에 대한 예측, 측정 정의를 바꾸었을 때의 안정성으로 판단한다. 큰 코퍼스가 언제나 더 현실적인 빈도를 주거나 의미 구분판이 언제나 더 좋은 측정이라고 가정하지 않는다. 첫 분석에서 나온 상관만으로 인과효과를 확정하지 않는다.

상세 가설·모집단·분모·모형·문헌 검토 범위는 [빈도효과 측정 계획](../decisions/PLAN_frequency_effect_measurement_20260912.md)에 정리했다.

## 8. AP/IP 후보를 사용할 때

| 기계 분류 | 위치 수 | 해석 |
|---|---:|---|
| AP 후보 | 655 | 제한된 단서 조합을 만족 |
| IP 후보 | 1,144 | 쉼과 구말 F0 변화 등의 조건을 만족 |
| 불확실 | 3,912 | 설정 민감 등으로 판단 보류 |
| 평가 불가 | 168,435 | 층 연결·발음/음소 대응·F0·화자 등 제한 |
| 경계 단서 미검출 | 128,142 | 경계가 없다는 정답이 아님 |

후보 수를 현상의 빈도로 사용하지 않는다. 이 버전은 쉼 없는 IP, 복잡한 구말 성조, H로 시작하는 AP, 짧은 AP 등을 충분히 다루지 않는다. 기존 48곳 검토 자료에서 서로 다른 상태의 사례를 골라 먼저 청취할 수 있지만, 이 선택 표본으로 전체 정밀도·재현율을 추정하지 않는다.

## 9. 우선 읽을 문헌

- [Lee & Kapatsinski, Frequency Effects in Morphologisation of Korean /n/-Epenthesis](https://cpb-us-e1.wpmucdn.com/blogs.uoregon.edu/dist/a/6941/files/2014/11/LeeKapatsinskiSub-s3ss6n.pdf): 전체어 빈도·형태 구성·환경을 연결한 직접 관련 원고. 주관적 빈도 측정 방법을 확인할 출발점. 최종 출판 서지는 별도 확인 필요.
- [Song & Dalola (2019)](https://journals.linguisticsociety.org/proceedings/index.php/PLSA/article/view/4539), [후속 2024 논문](https://doi.org/10.18855/lisoko.2024.49.3.004): ㄴ삽입과 화자별 친숙도. 친숙도를 단일 코퍼스 빈도와 동일시하지 않을 근거.
- [Brysbaert & New (2009)](https://biblio.ugent.be/publication/599801): 널리 쓰이는 빈도 규준의 타당성과 대안 비교. 영어 단어 인식의 결과를 한국어 음운현상에 곧바로 일반화하지 않음.
- [Gries (2008)](https://www.stgries.info/research/2008_STG_Dispersion_IJCL.pdf): 출현 횟수와 분산의 차이. 구현 때 [정정·후속 자료](https://www.stgries.info/research/dispersion/links.html)도 확인.
- [Bell et al. (2009)](https://web.stanford.edu/~jurafsky/bell09.pdf): 빈도·문맥 예측 가능성·반복의 구분. 지속시간과 삽입/탈락 여부의 종속변수 차이에 유의.
- [KoFREN (2024)](https://aclanthology.org/2024.lrec-main.866/): 확보한 구어 빈도 비교 자료의 방법과 범위. 원 COUNT, 조정값, 이번 표의 분모를 구분.

로컬 ㄴ삽입 및 세미나 리딩, 전체 참고문헌 파일명과 Dropbox 관련 자료를 검색했고 위의 직접 관련 원문·공식 출처를 확인했다. 모든 현상의 빈도효과를 망라한 체계적 문헌고찰은 아직 하지 않았다. 강범모·김흥규 자료와 KoFREN의 집계 규약이 이번 단어 구성과 완전히 같다는 주장도 하지 않는다.

## 10. 이번 Git 반영 범위와 로컬 보존

이번 반영 대상은 이 Markdown·동일 내용의 HTML, 빈도효과 측정 계획, 빈도 단위 및 AP/IP 후보 핵심 코드와 합성 검사, README 연결이다. 실행 중인 코드의 내용을 바꾸지 않고 공개 가능한 핵심 파일을 그대로 기록한다.

장치 경로에 연결된 대량 실행기, 원 음성·전사·TextGrid, 화자 정보, 대형 CSV/JSON/SQLite, API 정보, 문헌 원문, 실행 로그와 다른 작업의 미정리 변경은 로컬에 보존한다. 공개 저장소만으로 허가 대상 코퍼스나 전체 실행 환경이 제공되는 것은 아니다. 실제 파일 위치·완료 manifest·실행 PID는 별도 로컬 안내에 기록한다.

다음 연구 단계는 하나의 현상을 정하고, 그 현상의 반복 경험을 나타낼 측정 후보를 명시한 표와 실제 발음 검토 표본을 함께 만드는 것이다. 빈도사전 전수 실행이 끝나면 최종 분모·미결정·품사 범위·중복 보류를 확인하고 사용할 버전을 고정한다.
