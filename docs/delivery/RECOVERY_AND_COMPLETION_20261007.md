# 복구된 연구 프로젝트와 로컬 배포 완료

2026-10-07 사용자는 음성 예외를 명시한 범위로 배포 준비를 마무리하도록 승인했다.
로컬 패키지의 최종 기준은 `DELIVERY_FINAL.json`이며 자동 배포 점검은 일시정지했다.

## 완료 범위

- 최신 형태소 CSV, 담화 JSON, 공통 Parquet, 정렬 동반표와 상대경로 연결.
- 모두의 형태소 층을 제거한 5층 TextGrid와 서울 원본 7층 자료 보존.
- 과거 분석과 보완자료, 비교·보류 목록, Python/R 열람·조회 도구.
- 완료된 독립 복사/SHA 감사 및 승인된 SHA 재사용 기록, 후속 소파일 무결성 검사.
- 기존 Python/R 조회 및 다른 루트 재열기 검증 근거 보존.

전체 전사·분석 ID는 보존했다. 음성 1,436개는 미확보·대응 미확정 예외다.
이 중 2023년 400개에는 저장 대응 후보가 있으나 적용하지 않았다.
원음성 전체 확보, 전역 부재 또는 후보의 정답 여부를 입증한 것이 아니다.
확정 기술 수정은 0건이며 언어학적 보류는 연구자 검토 대상으로 남는다.
공급자 버전 선언과 개별 응답 미검증(`runtime_version_verified=false`)을 구분한다.

## GitHub와 로컬 패키지의 역할

GitHub에는 경로 인자를 받는 조회·검증·재개·별도 수정 도구와 합성 시험,
완료 범위 설명을 보존한다. 저장소를 받는 것만으로 연구 데이터가 내려오지는 않는다.
라이선스가 적용되는 원음성·전사·원응답, 대량 산출물·장부와 실제 발화별 근거는
검증된 로컬 패키지에 보존한다. 장치별 실행기와 설정도 로컬 인계에 남는다.

다른 기기에서 이어갈 때는 다음 순서로 확인한다.

1. 이 저장소와 프로젝트 시작 안내를 읽는다.
2. 로컬 패키지의 `START_HERE_COMPLETED.md`, `DELIVERY_FINAL.json`을 읽는다.
3. `metadata/audio_scope_decision_v1`의 예외 목록과 승인 근거를 확인한다.
4. 패키지 경로를 명시하여 조회 도구를 사용한다. 원문·좌표·버전을 추정해 바꾸지 않는다.

대량 실행기나 전체 재해시를 연구 시작의 기본 작업으로 다시 실행하지 않는다.
새 분석·수정은 원본을 보존하면서 별도 결과로 기록한다. 외부 공개·업로드·메일
발송은 이번 로컬 배포 준비에 포함되지 않았다.

## 도구와 시험

Python 도구는 `scripts/python`, R 도구는 `scripts/R`, 합성 시험은 `tests`에 있다.
Parquet 조회·수정에는 Python `pyarrow`가 필요하다. Windows의 수정·재개 제어는
표준 `msvcrt` 잠금을 사용한다. R 관련 시험은 실제 R 및 필요한 패키지가 있을 때
실행하며 누락 환경은 시험 결과에서 구분한다.

R Arrow는 `scripts/R/prepare_delivery_arrow.R`로 별도 라이브러리에 준비한다.
독립 검증용 복사본에서는 `DELIVERY_R_LIBRARY`로 이미 설치한 라이브러리를,
필요하면 `DELIVERY_RSCRIPT`로 Rscript 실행파일을 명시한다. 실제 자료나 로컬
코드가 필요하다는 의미가 아니라 시험의 외부 런타임 의존성을 명시하는 것이다.

게시 대상만 모은 독립 검증 환경에서 시험한 결과와 파일 목록은
`GIT_PUBLICATION_VALIDATION_20261007.json`에 기록한다. 이 시험은 코드의 합성
검증이며 실제 전수 데이터 재처리나 새로운 전체 데이터 SHA 감사가 아니다.
