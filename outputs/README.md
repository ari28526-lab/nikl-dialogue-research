# outputs

최종에 가까운 산출물을 두는 곳입니다.

```text
figures   논문/보고서용 그림
tables    분석 표
reports   HTML/PDF/문서 보고서
reviews   연구자 검토표·작은 근거 manifest
archive   완료 파일럿·중복 검토본의 로컬 보존(현재 정본 아님)
```

임시 결과는 `work`에 두고, 공유하거나 보존할 결과만 이곳으로 옮깁니다.
대형 WAV·TextGrid·DB와 로컬 review payload는 Git에 넣지 않고, 최종 계약·감사·
승인에 필요한 작은 JSON/CSV만 추적합니다.
