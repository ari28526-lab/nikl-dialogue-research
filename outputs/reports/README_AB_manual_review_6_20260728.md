# 공통 발음 사전 A/B 우선 검토 6개

이 폴더는 공통 발음 사전 A/B 파일럿의 수동 검토를 쉽게 하기 위해 만든 복사본이다.
원래 파일은 이동하거나 수정하지 않았다.

## 파일 이름

- `audio.wav`: A와 B에서 공통으로 사용하는 동일한 음성
- `A_base_g2p.TextGrid`: 기존 G2P 중심 사전으로 정렬한 결과
- `B_plus_dictionary.TextGrid`: 기존 G2P에 우리말샘 예외 발음 후보를 추가한 결과

## 우선 검토

다음 세 발화에서는 A와 B의 phone 배열이 실제로 달라졌다.

1. `SDRW2000001214.1.1.95` — `있다`
2. `SDRW2300000171.1.1.108` — `그것`
3. `SDRW2400002901.1.1.111` — `수가`

Praat에서 같은 발화의 `audio.wav`와 A TextGrid를 함께 연 다음, 같은 음성에 B
TextGrid를 연결하여 비교한다. 각 발화에 대해 `A 우세`, `B 우세`, `차이 불명확`,
`B 오정렬` 중 하나와 간단한 근거를 기록한다.

## 대조군

나머지 세 발화는 발음 후보가 바뀌지 않았지만 A/B 실행 간 경계가 달라진 사례다.
대조군의 차이는 독립 정렬 실행에서 발생하는 변동의 기준으로 사용한다.

1. `SDRW2200002747.1.1.172`
2. `SDRW2000001214.1.1.275`
3. `SDRW2500000651.1.1.221`

이 검토는 우리말샘 발음을 공통 레지스트리에 수록할지를 결정하는 절차가 아니다.
예외 발음 후보를 MFA 활성 사전에 넣었을 때 명백한 오정렬이 생기는지와 추가 적용
조건이 필요한지를 확인하는 안전성 점검이다.
