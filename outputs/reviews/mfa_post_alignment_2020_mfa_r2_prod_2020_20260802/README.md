# 2020 post-MFA 정렬 실패 검토

이 묶음은 2020년 전수 MFA가 끝난 뒤 word/phone interval이 생성되지 않은
363개 발화를 확인하기 위한 자료이다. 자동 제외 승인은 하지 않았다.

## 먼저 볼 것

`03_AUDIO_LAB_PILOT_REVIEW.csv`를 열고 1번부터 WAV를 재생하면서 같은 이름의
LAB 및 `normalized_text`와 실제 발화가 일치하는지 확인한다.

- 1~4번: 실패 200건이 몰린 `SDRW2000000257`의 대표 실패 발화
- 5~12번: 다른 세션의 대표 실패 발화
- 13~16번: `SDRW2000000257`에서 정상 정렬된 대조 발화

`decision`에는 `match`, `mismatch`, `uncertain` 중 하나를 적고, 특이점은
`notes`에 적는다.

## 왜 이 확인이 필요한가

- 363건은 MFA 기본 beam=10과 retry_beam=40에서도 정렬되지 않았다.
- 그중 200건이 한 세션에 몰려 있어 단순 개별 음향 실패인지, WAV/LAB 매핑
  문제인지 먼저 구분해야 한다.
- 이 세션은 2020 WAV ID 복구 계획의 영향 대상이 아니며, 2026-07-26 구방식
  정렬에서도 205건이 실패했다. 이번 200건 중 193건은 그때와 같은 ID다.
  따라서 새 WAV 복구가 만든 회귀보다는 원자료 또는 세션 고유 난정렬일
  가능성이 높지만, 청취 확인 없이 단정하지 않는다.
- 구방식 전체 실패 3,644건 중 3,332건은 이번 공통 Jamo r2 정렬에서
  회수됐다. 이번 실패 363건 중 312건은 구방식에서도 실패한 지속 난정렬이고,
  51건은 이번에 새로 실패한 ID다.
- WAV와 LAB가 맞으면 표적 재정렬 또는 명시적 제외를 결정할 수 있다.
- WAV와 LAB가 다르면 해당 세션 입력 복구가 우선이며, 363건을 일괄 제외하면
  안 된다.
